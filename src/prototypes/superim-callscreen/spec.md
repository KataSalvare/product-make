# CallScreen Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | CallScreen |
| **页面路径** | /callscreen |
| **页面类型** | 通话页 |
| **目标用户** | 通话双方 |
| **页面目的** | 语音/视频通话界面 |

### 1.2 页面描述
通话界面，支持语音和视频通话，显示通话状态、时长、网络质量，提供静音、免提、视频开关、挂断等控制功能。

## 3. 交互逻辑

### 3.1 通话状态
| 状态 | 显示 |
|------|------|
| calling | "Calling..." + 脉冲动画 |
| ringing | "Ringing..." |
| connected | 通话时长计时 |
| ended | "Call ended" |

### 3.2 控制按钮
| 按钮 | 功能 | 激活状态 |
|------|------|----------|
| Mute | 静音/取消静音 | 主色背景 |
| Video | 开启/关闭视频 | 主色背景(关闭时) |
| Speaker | 免提/听筒 | 主色背景 |
| Flip | 切换前后摄像头 | 无激活状态 |

### 3.3 视频通话
- 开启视频时显示小窗口预览
- 点击可切换大小窗口
- 关闭视频只显示头像

### 3.4 通话计时
- 连接成功后开始计时
- 格式 MM:SS
- 显示在顶部状态栏

### 3.5 网络质量
- 实时检测网络状态
- 4格信号指示
- 文字提示 Good/Poor/Bad

### 3.6 挂断通话
- 点击红色挂断按钮
- 显示"Ending..."
- 结束后返回上一页

### 3.7 最小化通话
- 下滑手势最小化
- 悬浮窗显示通话中
- 点击恢复全屏

## 5. 异常处理

### 5.1 通话中断
- 网络断开提示"Connection lost"
- 自动重连3次
- 失败显示"Call failed"

### 5.2 对方挂断
- 显示"Call ended"
- 显示通话时长
- 2秒后自动返回

### 5.3 权限拒绝
- 麦克风/相机权限被拒
- 显示提示引导开启
- 提供设置入口
