# Feed Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | Feed Page |
| **页面路径** | /feed |
| **页面类型** | 社交页 |
| **目标用户** | 已登录用户 |
| **页面目的** | 浏览和发布社交动态 |

### 1.2 页面描述
社交动态页面，展示好友的朋友圈内容，支持发布文字、图片、视频动态，点赞、评论互动。

## 3. 交互逻辑

### 3.1 动态互动

#### 点赞
- 单击：点赞/取消点赞
- 动画：心形缩放动画
- 实时：点赞数即时更新

#### 评论
- 点击：展开评论区
- 输入：底部弹出评论框
- 发送：实时显示评论

#### 分享
- 点击：显示分享选项
- 选项：转发给好友、复制链接、其他应用

### 3.2 发布动态
- 点击相机/编辑按钮
- 跳转到 NewPost 页面
- 支持：文字、图片(最多9张)、视频

### 3.3 故事功能
- 横向滚动展示
- 点击：全屏查看故事
- 添加：点击我的故事 + 号

### 3.4 下拉刷新
- 下拉刷新动态列表
- 上滑加载更多

---

## 4. 内容规范

### 4.1 时间格式
| 时间范围 | 显示 |
|----------|------|
| < 1小时 | Xm |
| < 24小时 | Xh |
| < 7天 | Xd |
| 更早 | 日期 |

### 4.2 媒体展示
- 单图：自适应宽度，最大高度限制
- 多图：网格布局（2-9张）
- 视频：封面图 + 播放按钮

---

## 5. 异常处理

### 5.1 空状态
- 无动态：显示"No posts yet" + 发布引导
- 加载失败：重试按钮

---

## 6. 主题适配

使用 Equatorial Minimalism 主题，卡片使用 surface-container 背景。
