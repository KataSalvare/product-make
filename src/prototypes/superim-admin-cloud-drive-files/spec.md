# SuperIM v1.2 云盘文件管理规格

## 页面信息
- 页面名称：文件管理
- 页面路径：`/admin/cloud-drive/files`
- 所属模块：云盘管理

## 页面目标
以表格管理文件元数据和生命周期状态。后台不显示文件正文、不提供预览、不提供下载。

## 字段与筛选
- 表格字段：文件名/文件 ID、类型、大小、所属用户/用户 ID、来源、所属文件夹、状态、更新时间。
- 支持按文件名或用户 ID 搜索；按类型、来源、状态、更新时间筛选；按名称、大小、更新时间排序。
- 支持当前页全选、分页、空结果状态和元数据详情抽屉。

## 变更交互
- 冻结和批量冻结必须填写原因；冻结后从前台云盘和 Picker 隐藏，但容量仍计入。
- 解冻后恢复前台显示和使用。
- 永久删除使用二次确认，立即硬删除并释放容量；不可恢复。
- 抽屉仅展示元数据和状态说明，不出现正文预览或下载按钮。
- 冻结、解冻、永久删除全部写入操作审计。
