# SuperIM 敏感词库页规格文档

## 页面信息
- **页面名称**: 敏感词库
- **页面路径**: /admin/messages/sensitive-words
- **所属模块**: 消息管理模块

## 功能描述
管理敏感词库，支持添加、编辑、删除敏感词，按分类管理，支持批量导入导出，维护平台内容安全。

## 组件清单

### 1. 敏感词统计卡片
- **组件类型**: 数据卡片
- **数量**: 4个
- **布局**: 4列等宽
- **卡片内容**:
  - 分类名称
  - 词汇数量 (大字体)
  - 占比进度条
  - 图标

**分类定义**:
| 分类 | 数量 | 图标 | 颜色 |
|------|------|------|------|
| 政治敏感 | 156 | ShieldAlert | 红色 |
| 色情暴力 | 234 | AlertTriangle | 橙色 |
| 广告诈骗 | 89 | Ban | 黄色 |
| 其他 | 45 | MoreHorizontal | 灰色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持敏感词/替换词）
  - 分类下拉筛选（全部/政治敏感/色情暴力/广告诈骗/其他）
  - 匹配模式下拉筛选（全部/精确匹配/模糊匹配/正则匹配）
  - 搜索按钮
  - 重置按钮

### 3. 批量操作栏
- **组件类型**: 工具栏
- **内容**:
  - 全选复选框
  - 已选数量显示
  - 批量删除按钮（需二次确认）
  - 批量移动分类按钮

### 4. 敏感词表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 选择框 | 50px | 单选复选框 |
  | 敏感词 | 200px | 敏感词汇内容 |
  | 分类 | 120px | 所属分类标签 |
  | 匹配模式 | 100px | 精确/模糊/正则 |
  | 替换词 | 150px | 替换显示内容 |
  | 添加时间 | 150px | YYYY-MM-DD HH:mm |
  | 操作 | 150px | 编辑/删除 |

### 5. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50/100）
  - 页码导航
  - 总记录数显示

### 6. 添加/编辑敏感词对话框
- **组件类型**: 对话框
- **内容**:
  - 敏感词输入框（必填）
  - 分类选择（政治敏感/色情暴力/广告诈骗/其他）
  - 匹配模式选择（精确匹配/模糊匹配/正则匹配）
  - 替换词输入框（可选，为空则拦截）
  - 确认按钮
  - 取消按钮

### 7. 批量导入对话框
- **组件类型**: 对话框
- **内容**:
  - 文件上传区域（支持Excel/CSV）
  - 模板下载链接
  - 导入预览（前10条）
  - 确认导入按钮
  - 取消按钮

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 添加敏感词
1. 点击"添加敏感词"按钮
2. 弹出添加对话框
3. 填写敏感词信息
4. 点击确认添加

### 编辑敏感词
1. 点击操作列的"编辑"按钮
2. 弹出编辑对话框，预填充当前数据
3. 修改敏感词信息
4. 点击确认保存

### 删除敏感词
1. 点击操作列的"删除"按钮或选择批量删除
2. 弹出确认对话框
3. 确认后删除敏感词

### 批量导入
1. 点击"批量导入"按钮
2. 弹出导入对话框
3. 上传Excel/CSV文件
4. 预览导入数据
5. 确认导入

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（替换词、添加时间）
- **移动端**: 卡片式列表展示
