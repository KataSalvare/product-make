# NewPost Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | NewPost Page |
| **页面路径** | /new-post |
| **页面类型** | 发布页 |
| **目标用户** | 已登录用户 |
| **页面目的** | 发布社交动态，支持文字、图片、位置和表情 |

### 1.2 页面描述
发布动态页面，支持发布文字、图片、视频内容，可添加位置标签和表情符号，提供实时字数统计和媒体预览功能。

## 3. 交互逻辑

### 3.1 文字输入
- 自适应高度
- 最大 500 字符
- 接近限制时变红警告

### 3.2 表情选择器

| 操作 | 行为 |
|------|------|
| 点击表情按钮 | 展开/收起表情面板 |
| 点击表情 | 插入到光标位置 |
| 超过字符限制 | 禁止插入 |
| 面板展开时 | 位置面板自动收起 |

**表情面板规格：**
- 8列网格布局
- 96个常用表情
- 最大高度 192px，可滚动
- 点击表情后保持面板打开

### 3.3 位置选择器

| 操作 | 行为 |
|------|------|
| 点击位置按钮 | 展开/收起位置面板 |
| 搜索位置 | 实时过滤位置列表 |
| 点击位置项 | 选中并添加标签 |
| 已选位置 | 显示勾选标记 |
| 面板展开时 | 表情面板自动收起 |

**位置面板规格：**
- 顶部搜索框
- 位置列表（名称+地址）
- 最大高度 160px，可滚动
- 选中后自动收起面板

### 3.4 位置标签
- 显示在文本区域下方
- 圆角胶囊样式
- 包含位置图标、名称、删除按钮
- 点击删除按钮移除位置

### 3.5 媒体添加

| 方式 | 操作 |
|------|------|
| 相册 | 选择多张图片（最多9张） |
| 相机 | 拍照或录像 |

### 3.6 媒体预览
- 点击删除单个媒体
- 长按拖动排序
- 点击预览大图

### 3.7 发布流程
```
输入内容/选择媒体/添加位置
        │
        ▼
   点击 Post
        │
        ▼
   验证内容
        │
    ┌───┴───┐
    │       │
  有效     无效
    │       │
    ▼       ▼
  显示加载  显示错误
    │
    ▼
  上传媒体
    │
    ▼
  发布成功
    │
    ▼
  返回 Feed
```

### 3.8 可见性设置
- 点击 Public ▼
- 选项：
  - Public（公开）
  - Friends Only（仅好友）
  - Private（私密）

## 4. 内容规范

### 4.1 字数限制
| 限制 | 说明 |
|------|------|
| 最大字符 | 500 |
| 警告阈值 | 450（变橙色） |
| 超限阈值 | 500（变红色，禁止发布） |

### 4.2 媒体限制
| 类型 | 限制 |
|------|------|
| 图片数量 | 最多9张 |
| 单张大小 | 最大10MB |
| 视频时长 | 最长60秒 |
| 视频大小 | 最大50MB |

### 4.3 位置数据
```typescript
interface LocationInfo {
  name: string;      // 城市名称
  address: string;   // 详细地址
}
```

### 4.4 表情数据
- 96个常用表情符号
- 分类：表情、爱心、手势、符号
- 点击直接插入文本

---

## 5. 异常处理

### 5.1 发布失败
- 显示错误提示
- 保留内容，可重试

### 5.2 媒体上传失败
- 单个失败可删除重选
- 显示具体错误原因

### 5.3 位置搜索无结果
- 显示"No locations found"
- 提示用户修改搜索词

## 7. 状态管理

```typescript
interface NewPostState {
  content: string;
  attachedMedia: AttachedMedia[];
  isPosting: boolean;
  showEmojiPicker: boolean;
  showLocationPicker: boolean;
  selectedLocation: LocationInfo | null;
  searchLocation: string;
}
```

### 7.1 按钮状态

**表情按钮：**
- 默认：hover:bg-[var(--surface-container-high)]
- 激活（面板展开）：bg-[var(--secondary-container)]

**位置按钮：**
- 默认：hover:bg-[var(--surface-container-high)]
- 激活（面板展开或已选位置）：bg-[var(--secondary-container)]

**Post按钮：**
- 禁用：bg-[var(--surface-container)]
- 可用：bg-[var(--secondary)]
