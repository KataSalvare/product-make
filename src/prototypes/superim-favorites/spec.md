# Favorites Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | Favorites Page |
| **页面路径** | /favorites |
| **页面类型** | 子页面 |
| **目标用户** | 已登录用户 |
| **页面目的** | 查看、搜索、筛选用户收藏的消息、图片、视频、链接和文件 |

### 1.2 页面描述
用户通过「个人中心 > My Favorites」或聊天消息长按菜单进入收藏夹首页。页面以类型 Tab 分类展示所有收藏内容，支持搜索和按类型筛选。单条收藏支持右键（桌面端）或长按（移动端）唤起操作菜单，菜单提供 Forward / Multi-select / Delete。进入多选模式后，可选择多条收藏进行批量 Forward 或批量 Delete。

## 2. 展示逻辑

### 2.1 布局结构
```
┌─────────────────────────────────────┐
│ ← Favorites          [Select All]   │ ← Header（多选模式显示数量+全选）
├─────────────────────────────────────┤
│ [🔍 Search favorites...]            │ ← 搜索栏
├─────────────────────────────────────┤
│ [All] [Text] [Image] [Video] ...    │ ← 类型筛选 Tab
├─────────────────────────────────────┤
│                                     │
│  ┌───────────────────────────────┐  │
│  │ [icon] Source          Time   │  │
│  │ Preview / Content             │  │ ← 收藏卡片列表（选中时高亮）
│  └───────────────────────────────┘  │
│                                     │
├─────────────────────────────────────┤
│ [Forward]        [Delete]           │ ← 多选模式底部操作栏
└─────────────────────────────────────┘
```

### 2.2 视觉层级
| 层级 | 元素 | 说明 |
|------|------|------|
| 1 | Header | 返回按钮、页面标题；多选模式显示已选数量+全选按钮 |
| 2 | 搜索栏 | 支持按内容或来源搜索收藏 |
| 3 | 类型 Tab | All / Text / Image / Video / Link / File |
| 4 | 收藏卡片 | 图标、来源、时间、内容预览；选中时显示勾选标记并高亮 |
| 5 | 右键菜单 | Forward / Multi-select / Delete |
| 6 | 底部操作栏 | 多选模式出现，Forward / Delete |
| 7 | 删除确认弹窗 | 单条/批量删除前二次确认 |

### 2.3 收藏类型
- **text**：文本消息，显示内容摘要
- **image**：图片，显示缩略图
- **video**：视频，显示缩略图和播放按钮
- **link**：链接，显示标题或 URL
- **file**：文件，显示文件名和大小

## 3. 交互逻辑

### 3.1 搜索
- 输入关键词实时过滤收藏内容
- 匹配内容（content）或来源（source）
- 清空按钮快速重置搜索

### 3.2 类型筛选
- 点击 Tab 切换 activeFilter
- 仅展示对应类型的收藏

### 3.3 进入详情
- 非多选模式下点击收藏卡片跳转到 `/favorite/:id`

### 3.4 右键/长按操作菜单
- 触发方式：桌面端右键点击卡片，移动端长按卡片 600ms
- 菜单位置：以点击/长按位置为锚点，使用 `fixed` 定位在触发点附近弹出；自动检测屏幕右/下边界，超出时向左/上偏移，保证菜单完整可见
- 关闭方式：点击菜单外部区域或选择菜单项后自动关闭
- 菜单项：
  - **Forward**：跳转 `/forward-message?favoriteId=xxx`，将当前收藏转发到聊天/群聊
  - **Multi-select**：进入多选模式，并默认选中当前收藏
  - **Delete**：弹出二次确认弹窗，确认后从列表移除

### 3.5 多选模式
- Header 变为「X selected」，右侧显示「Select All」
- 每条收藏卡片左侧显示勾选圆圈；点击卡片切换选中状态
- 底部固定操作栏：Forward / Delete
- 点击空白处或右上角关闭按钮退出多选模式

### 3.6 批量转发
- 点击底部 Forward 按钮，跳转 `/forward-message?favoriteId=xxx&favoriteId=yyy`
- 可一次转发多条收藏内容

### 3.7 批量删除
- 点击底部 Delete 按钮，弹出确认弹窗「Delete X items?」
- 确认后移除所有已选收藏，并退出多选模式

### 3.8 空状态
- 无收藏或搜索无结果时显示空状态插画和提示文案

## 4. 主题适配

使用主题变量：
- `--surface` 页面背景
- `--surface-container-low` Header / 搜索栏背景
- `--surface-container-lowest` 卡片背景
- `--primary` 链接文本色
- `--secondary` 选中 Tab / 来源文本色
- `--on-surface` 主要文本色
- `--on-surface-variant` 次要文本色
- `--outline-variant` 分割线、边框
