# Favorites Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | Favorites / Saved Messages |
| **页面路径** | /favorites |
| **页面类型** | 子页面 |
| **目标用户** | 已登录用户 |
| **页面目的** | 以「发给自己的对话」形式查看、搜索、发送和管理收藏内容 |

### 1.2 页面描述
参考 Telegram Saved Messages 交互：收藏夹本质上是用户与自己的对话。页面顶部为 Header，中间按时间正序展示所有收藏消息（新消息在底部追加），底部提供输入框，可发送文字笔记给自己。任意消息长按（桌面端右键）唤起操作菜单，支持 Reply / Forward / Copy / Delete / Select。收藏来源在消息气泡上方以较小字体展示。页面支持「聊天模式」与「消息模式」两种视图，默认聊天模式。

## 2. 展示逻辑

### 2.1 布局结构
```
┌─────────────────────────────────────┐
│ ← Saved Messages        [🔍] [⋮]   │ ← Header（⋮ 展开视图切换菜单）
├─────────────────────────────────────┤
│  ┌─────────────────────────────┐    │
│  │ Chat Mode     ✓             │    │
│  │ Message Mode                │    │
│  └─────────────────────────────┘    │
├─────────────────────────────────────┤
│                                     │
│  Source: Design Team                │
│  ┌─────────────────────────────┐    │
│  │ Beautiful sunset at the...  │    │ ← 文本气泡（聊天模式，靠右）
│  └─────────────────────────────┘    │
│              Today 10:30            │
│                                     │
├─────────────────────────────────────┤
│ [🎙] [输入框...]        [➤]         │ ← 底部输入区
└─────────────────────────────────────┘
```

消息模式（Message Mode）下，列表改为平铺的消息行，每行显示来源头像、来源名称、内容摘要与时间。

### 2.2 视觉层级
| 层级 | 元素 | 说明 |
|------|------|------|
| 1 | Header | 返回按钮、标题「Saved Messages」、搜索按钮、更多按钮（视图切换） |
| 2 | 视图菜单 | Chat Mode / Message Mode，默认 Chat Mode |
| 3 | 消息列表 | 按时间正序展示收藏消息，新消息在底部追加 |
| 4 | 来源标签 | 每条消息顶部显示来源聊天/用户（聊天模式） |
| 5 | 消息气泡 | 文本、图片、视频、链接、文件按类型渲染（聊天模式） |
| 6 | 消息行 | 来源头像、名称、内容摘要、时间（消息模式） |
| 7 | 长按菜单 | Reply / Forward / Copy / Delete / Select |
| 8 | 多选模式 | Header 显示已选数量 + 关闭/全选，底部 Forward / Delete |
| 9 | 底部输入框 | 与单聊发送操作栏保持一致：附件按钮、带表情按钮的输入框、语音/发送按钮；图标按钮与输入框垂直居中对齐；用于发送文字笔记给自己，发送后追加到列表底部 |

### 2.3 收藏类型渲染
- **text**：圆角气泡内显示文本内容
- **image**：图片气泡，点击放大预览
- **video**：视频缩略图气泡，带播放按钮
- **link**：链接卡片，显示标题/URL，点击外部打开
- **file**：文件卡片，显示文件名、大小，点击可下载

## 3. 交互逻辑

### 3.1 进入页面
- 从聊天列表顶部「Saved Messages」固定入口、个人中心或聊天消息长按菜单进入
- 默认按时间正序排列，新消息在底部追加
- 默认视图模式为「聊天模式」

### 3.2 发送笔记
- 底部输入框输入文字
- 点击发送按钮或按回车
- 新增一条 `type: 'text'`，`isFromMe: true`，`source: 'You'` 的收藏消息，追加到列表底部并自动滚动到底部

### 3.3 消息长按/右键菜单
- 触发方式：桌面端右键，移动端长按 600ms
- 菜单位置：以触发位置为锚点，fixed 定位，屏幕边界自适应
- 菜单项：
  - **Reply**：引用该消息，在输入框上方显示引用提示，发送后生成带 reply 引用的笔记
  - **Forward**：跳转 `/forward-message?favoriteId=xxx`
  - **Copy**：复制文本/链接内容到剪贴板，显示 Toast
  - **Delete**：直接删除或弹窗确认后删除
  - **Select**：进入多选模式并选中当前消息

### 3.4 多选模式
- Header 变为「X selected」+ 关闭按钮 + Select All
- 每条消息左侧/右上角显示勾选标记
- 底部固定操作栏：Forward / Delete
- 点击空白处或关闭按钮退出

### 3.5 视图模式切换
- 点击 Header 右上角「⋮」更多按钮，展开视图切换菜单
- **Chat Mode**：以聊天气泡形式展示消息，来源标签在气泡上方，时间右对齐
- **Message Mode**：以列表行形式展示消息，每行包含来源头像、来源名称、内容摘要、时间
- 默认选中 Chat Mode，切换后保持当前滚动位置

### 3.6 搜索
- 点击 Header 搜索图标，顶部展开搜索输入框
- 实时按内容/来源过滤消息列表，两种视图下均生效

### 3.7 空状态
- 无收藏时显示「No saved messages yet」提示
- 引导用户长按聊天消息选择「Save to Favorites」

## 4. 数据模型

```ts
interface Favorite {
  id: string;
  type: 'text' | 'image' | 'video' | 'link' | 'file';
  source: string;          // 来源聊天/用户，自己发送的笔记为 "You"
  content: string;         // 文本内容或链接
  preview?: string;        // 图片/视频缩略图
  title?: string;          // 链接标题
  url?: string;            // 链接 URL
  fileName?: string;       // 文件名
  fileSize?: string;       // 文件大小
  time: string;            // 收藏/发送时间
  isFromMe?: boolean;      // 是否为自己发送的笔记
  replyTo?: { id: string; content: string }; // 引用消息
}
```

## 5. 主题适配

使用主题变量：
- `--surface` 页面背景
- `--surface-container-low` Header / 输入框背景
- `--surface-container-lowest` 消息气泡背景
- `--primary` 链接/发送按钮
- `--secondary` 来源标签
- `--on-surface` 主要文本色
- `--on-surface-variant` 次要文本/时间色
- `--outline-variant` 分割线、边框
