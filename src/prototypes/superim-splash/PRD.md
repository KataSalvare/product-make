# Splash Screen PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | Splash Screen |
| **页面路径** | /splash |
| **页面类型** | 启动页 |
| **目标用户** | 所有用户 |
| **页面目的** | 展示品牌形象，提供应用加载过渡 |

### 1.2 页面描述
SuperIM 品牌启动页，展示品牌 Logo、名称和标语，通过流畅的入场动画建立高端品牌形象，2.5秒后自动过渡到登录页面。

## 3. 交互逻辑

### 3.1 动画序列

#### 入场动画（总时长 2500ms）
| 阶段 | 时间 | 动画效果 | 元素 |
|------|------|----------|------|
| 1 | 0-100ms | 等待 | - |
| 2 | 100-1100ms | 缩放 + 淡入 | Logo（scale: 0.75→1, opacity: 0→1） |
| 3 | 400-1400ms | 上移 + 淡入 | 品牌名（translateY: 16px→0, opacity: 0→1） |
| 4 | 600-1600ms | 上移 + 淡入 | 标语（translateY: 16px→0, opacity: 0→1） |
| 5 | 800-1800ms | 淡入 | 加载动画（opacity: 0→1） |
| 6 | 1100-2100ms | 淡入 | 版本号（opacity: 0→1） |
| 7 | 2500ms | 淡出 | 整个页面（opacity: 1→0） |

#### 加载动画
- 三个圆点依次弹跳
- 动画延迟：0ms, 150ms, 300ms
- 弹跳周期：约 600ms

### 3.2 状态流转
```
┌─────────┐    100ms    ┌─────────┐
│  Initial │ ──────────→│  Phase 1 │
└─────────┘             └────┬────┘
                             │
                    2400ms   │
                             ▼
┌─────────┐    500ms    ┌─────────┐
│  Login   │ ←──────────│  Exit   │
└─────────┘   (fade out) └─────────┘
```

### 3.3 过渡逻辑
- **自动过渡**：页面加载 2500ms 后自动淡出
- **淡出时长**：500ms
- **目标页面**：Login 页面

## 5. 异常处理

### 5.1 边界情况
| 场景 | 处理方案 |
|------|----------|
| 动画中断 | 直接跳转到登录页 |
| 页面预加载 | 保持动画完整播放 |
| 低性能设备 | 简化动画，保留基础过渡 |

## 6. 主题适配

### 6.1 主题变量使用
```css
/* 背景 */
background: var(--surface);

/* Logo */
background: var(--primary);
color: var(--on-primary);

/* 文字 */
color: var(--primary);        /* 品牌名 */
color: var(--on-surface-variant); /* 标语 */

/* 加载点 */
background: var(--secondary);
```

### 6.2 暗色模式适配
- 背景自动适配暗色主题
- Logo 保持品牌色不变
- 文字对比度自动调整

---

## 7. 性能优化

### 7.1 动画性能
- 使用 transform 和 opacity 实现动画（GPU 加速）
- 避免触发重排的属性
- 使用 will-change 提示浏览器优化

### 7.2 加载优化
- 背景装饰使用 CSS 实现，无需图片资源
- 字体预加载确保文字即时显示
