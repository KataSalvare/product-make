# SuperIM 评论管理页规格文档

## 页面信息
- **页面名称**: 评论管理
- **页面路径**: /admin/feed/comments
- **所属模块**: 动态管理模块

## 功能描述
管理平台用户发布的评论内容，支持搜索、筛选、审核、删除等操作，维护平台评论内容健康。

## 组件清单

### 1. 评论统计卡片
- **组件类型**: 数据卡片
- **数量**: 4个
- **布局**: 4列等宽
- **卡片内容**:
  - 指标名称
  - 数值 (大字体)
  - 图标

**指标定义**:
| 指标 | 数值 | 图标 | 颜色 |
|------|------|------|------|
| 今日评论 | 234 | MessageCircle | 蓝色 |
| 待审核 | 12 | Clock | 黄色 |
| 总评论 | 45,678 | MessageSquare | 绿色 |
| 已删除 | 123 | Trash2 | 红色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持用户名/评论内容关键词）
  - 状态下拉筛选（全部/正常/审核中/已删除）
  - 时间范围选择器
  - 搜索按钮
  - 重置按钮

### 3. 批量操作栏
- **组件类型**: 工具栏
- **内容**:
  - 全选复选框
  - 已选数量显示
  - 批量审核通过按钮
  - 批量删除按钮（需二次确认）

### 4. 评论表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 选择框 | 50px | 单选复选框 |
  | 用户 | 120px | 评论发布者用户名 |
  | 评论内容 | 300px | 评论内容，超长截断 |
  | 所属动态 | 200px | 被评论的动态内容预览 |
  | 状态 | 100px | 正常/审核中/已删除标签 |
  | 发布时间 | 150px | YYYY-MM-DD HH:mm |
  | 操作 | 150px | 查看/审核/删除 |

### 5. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50）
  - 页码导航
  - 总记录数显示

### 6. 评论详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 评论完整内容
  - 发布者信息
  - 所属动态内容
  - 发布时间
  - 点赞数
  - 回复列表
  - 操作按钮（审核/删除）

### 7. 审核对话框
- **组件类型**: 对话框
- **内容**:
  - 审核结果选择（通过/拒绝）
  - 审核备注输入框
  - 确认按钮
  - 取消按钮

### 8. 删除确认对话框
- **组件类型**: 确认对话框
- **内容**:
  - 删除确认提示
  - 删除原因选择（违规/广告/骚扰/其他）
  - 确认按钮（危险操作）
  - 取消按钮

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 批量操作
1. 勾选表格行选择评论
2. 点击全选选择当前页所有评论
3. 选择批量操作后弹出确认对话框
4. 确认后执行操作并刷新列表

### 单个操作
- **查看**: 打开评论详情抽屉
- **审核**: 打开审核对话框，选择通过或拒绝
- **删除**: 二次确认后删除（软删除）

### 审核流程
1. 点击"审核"按钮
2. 弹出审核对话框
3. 选择审核结果（通过/拒绝）
4. 填写审核备注（可选）
5. 点击确认
6. 更新评论状态并刷新列表

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（所属动态）
- **移动端**: 卡片式列表展示
