# My Posts Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | My Posts Page |
| **页面路径** | /myposts |
| **页面类型** | 个人页 |
| **目标用户** | 已登录用户 |
| **页面目的** | 查看和管理自己发布的所有动态 |

### 1.2 页面描述
展示当前用户发布的全部动态，按发布时间从新到旧排序。整体结构与 Feed 页面一致，但仅包含自己的帖子，便于回顾和整理。

---

### 2.2 视觉层级
| 层级 | 元素 | 说明 |
|------|------|------|
| 1 | Header | 返回按钮 + "My Posts" 标题 |
| 2 | 帖子卡片 | 头像、内容、图片、互动 |
| 3 | 图片网格 | 1/2/3/4 张自适应网格 |
| 4 | 操作栏 | Like + Comment 按钮 |
| 5 | 悬浮导航 | 底部导航 |

### 2.3 与 Feed 页面的区别

| 维度 | Feed | My Posts |
|------|------|----------|
| 作者 | 所有好友 | 仅当前用户（John Doe） |
| 排序 | 好友动态混合排序 | 按自己发布时间倒序 |
| 头像 | 各作者头像 | 统一为当前用户头像（primary 背景） |
| Header | 标题 + 发帖相机 | 返回按钮 + "My Posts" |
| 发帖入口 | "What's on your mind?" | 无（浏览模式） |

### 2.4 视觉设计

#### 颜色规范
| 元素 | 变量名 | 用途 |
|------|--------|------|
| 页面背景 | --surface | 主背景 |
| 卡片背景 | --surface-container-lowest | 帖子卡片 |
| 头像背景 | --primary | 统一深色头像 |
| 图片占位 | --surface-container | 图片网格背景 |
| 点赞激活 | --secondary | Like 按钮激活色 |

## 3. 交互逻辑

### 3.1 返回
- 点击 Header 返回箭头 → 返回 Me 页面

### 3.2 点赞
- 点击 Like 按钮切换点赞状态
- 点赞数实时更新

### 3.3 评论
- 点击 Comment 按钮进入评论（跳转 PostDetail）

### 3.4 底部导航
- 与所有页面一致的 Telegram 玻璃质感悬浮导航

---

## 4. 内容规范

### 4.1 排序规则
按帖子发布时间从新到旧排列（3 hours ago → Yesterday → 2 days ago → ...）

### 4.2 帖子内容
- 文字内容：完整显示
- 图片：1 图全宽、2 图双列、3 图三列、4 图 2×2

---

## 5. 主题适配

使用 Equatorial Minimalism 主题变量，与 Feed 页面保持一致。
