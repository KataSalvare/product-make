# Chats Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | Chats Page |
| **页面路径** | /chats |
| **页面类型** | 主页 |
| **目标用户** | 已登录用户 |
| **页面目的** | 展示聊天列表，快速访问最近对话 |

### 1.2 页面描述
应用主页面，展示用户的最近聊天列表，支持查看消息预览、未读数量、在线状态，提供快速搜索和新建聊天功能。

## 3. 交互逻辑

### 3.1 列表交互

#### 点击聊天项
- 行为：跳转到 ChatRoom 页面
- 过渡：右滑进入动画
- 未读状态：点击进入后清除未读数

#### 长按聊天项
- 行为：显示操作菜单
- 菜单选项：
  - Pin/Unpin（置顶/取消置顶）
  - Mute/Unmute（静音/取消静音）
  - Mark as Read/Unread（标记已读/未读）
  - Delete（删除）

#### 左滑快捷操作
- 行为：显示快捷操作按钮
- 滑动距离：超过 80px 显示完整操作
- 操作按钮：
  - 置顶（Pin）
  - 已读（Read）
  - 删除（Delete，红色背景）

### 3.2 Header 交互

#### 搜索按钮
- 点击搜索图标：展开搜索栏（覆盖 Header）
- 搜索栏结构：返回按钮 + 搜索输入框 + 清除按钮
- 输入时实时过滤聊天列表（按名称）
- 输入框左侧搜索图标，右侧清除按钮（有内容时显示）
- 返回按钮：关闭搜索栏，清空搜索词
- 无搜索结果时显示空状态提示

#### 新建聊天按钮（+）
- 点击"+"图标：展开下拉菜单，图标旋转45°
- 菜单选项：
  - **New Chat**：新建一对一聊天（跳转到联系人选择页面）
  - **New Group**：新建群聊（跳转到新建群聊页面）
- 点击菜单外区域关闭菜单
- 点击菜单项后自动关闭

### 3.3 下拉刷新
- 触发：列表顶部下拉超过 60px
- 反馈：显示刷新指示器
- 操作：重新加载聊天列表
- 完成：指示器消失，列表更新

### 3.4 悬浮导航
- 样式：Telegram 风格玻璃质感
- 位置：底部中央悬浮
- 选项：Chats、Contacts、Feed、Calls、Me
- 当前项：显示图标 + 文字标签
- 其他项：仅显示图标

## 4. 内容规范

### 4.1 时间显示格式
| 时间范围 | 显示格式 | 示例 |
|----------|----------|------|
| 今天 | HH:MM | 10:30 |
| 昨天 | Yesterday | Yesterday |
| 本周 | Day name | Mon |
| 更早 | MM/DD/YY | 12/25/23 |

### 4.2 消息预览规则
| 消息类型 | 预览显示 |
|----------|----------|
| 文字 | 前 40 个字符 |
| 图片 | 📷 Photo |
| 视频 | 🎥 Video |
| 语音 | 🎤 Voice message |
| 文件 | 📎 File name |
| 位置 | 📍 Location |
| 草稿 | Draft: 内容 |

### 4.3 排序规则
1. 置顶聊天（按置顶时间倒序）
2. 普通聊天（按最后消息时间倒序）

## 5. 异常处理

### 5.1 空状态
| 场景 | 显示内容 |
|------|----------|
| 无聊天记录 | 空状态插图 + "Start a conversation" |
| 搜索无结果 | "No chats found" |
| 网络错误 | 错误提示 + 重试按钮 |

### 5.2 加载状态
| 场景 | 处理方式 |
|------|----------|
| 初始加载 | 骨架屏（3-5 个占位项） |
| 下拉刷新 | 顶部刷新指示器 |
| 加载更多 | 底部加载动画 |
