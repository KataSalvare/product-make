# SuperIM 后台 Dashboard 规格文档

## 页面信息
- **页面名称**: 数据概览 Dashboard
- **页面路径**: /admin/dashboard
- **所属模块**: 数据概览模块

## 功能描述
展示平台核心运营数据，包括用户统计、消息统计、实时动态等关键指标，为管理员提供一目了然的运营状况视图。

## 组件清单

### 1. 核心指标卡片
- **组件类型**: 数据卡片
- **数量**: 6个
- **布局**: 3列 x 2行 (响应式)
- **卡片内容**:
  - 指标名称
  - 数值 (大字体)
  - 环比变化 (箭头 + 百分比)
  - 图标

**指标定义**:
| 指标 | 数值 | 图标 | 颜色 |
|------|------|------|------|
| 总注册用户 | 125,432 | Users | 蓝色 |
| 今日活跃用户 | 8,234 | Activity | 绿色 |
| 今日新增用户 | 456 | UserPlus | 橙色 |
| 当前在线用户 | 1,234 | Online | 紫色 |
| 今日消息数 | 45,678 | Message | 青色 |
| 今日通话时长 | 1,234分钟 | Phone | 粉色 |

### 2. 用户趋势图
- **组件类型**: 折线图
- **图表库**: ECharts
- **数据**: 近7天/30天/90天用户数据
- **线条**: 新增用户(蓝色)、活跃用户(绿色)、流失用户(红色)
- **交互**: 时间范围切换(7天/30天/90天)

### 3. 消息统计图
- **组件类型**: 组合图表
- **图表库**: ECharts
- **内容**: 
  - 柱状图: 单聊/群聊消息量对比
  - 饼图: 消息类型分布(文字/图片/语音/文件)

### 4. 用户分布饼图
- **组件类型**: 饼图
- **图表库**: ECharts
- **维度**: 
  - 按国家/地区分布
  - 按设备类型分布(iOS/Android/Web)

### 5. 实时动态列表
- **组件类型**: 列表
- **内容**:
  - 最新注册用户(5条)
  - 最新举报内容(5条)
  - 系统告警信息(如有)
- **刷新**: 每30秒自动刷新

## 响应式设计
- **桌面端(≥1280px)**: 6卡片一行, 图表双列
- **平板端(768-1279px)**: 3卡片一行, 图表单列
- **移动端(<768px)**: 2卡片一行, 图表单列
