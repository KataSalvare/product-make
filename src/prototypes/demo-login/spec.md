# 用户登录

## 📋 业务与功能

### 1.1 核心目标
> 提供用户登录入口，验证已有账号身份

### 1.2 功能清单
- **登录表单**：收集邮箱、密码
- **记住我**：可选的记住登录状态勾选
- **登录提交**：模拟提交登录信息
- **注册跳转**：引导无账号用户跳转注册页

### 1.3 交互要点
- 表单提交 → 控制台输出登录数据（Demo 阶段）
- 点击「立即注册」→ 路由跳转到 `/register`

---

## 📊 内容规划

### 2.1 信息架构

```
用户登录
├── 登录卡片
│   ├── 标题区域（"登录" + 欢迎文案）
│   ├── 表单区域
│   │   ├── 邮箱输入
│   │   ├── 密码输入
│   │   └── 记住我勾选
│   └── 底部区域（登录按钮 + 注册跳转链接）
```

### 2.2 数据来源
- **数据类型**：表单输入
- **数据源**：示例 Demo 数据
- **关键字段**：
  - `email`: string - 邮箱地址
  - `password`: string - 密码
  - `remember`: boolean - 记住我

---

## 🎨 布局与结构

### 3.1 整体布局
- **布局模式**：居中单栏卡片
- **容器宽度**：`max-w-md`（448px）
- **卡片结构**：Header + Content（表单）+ Footer（跳转链接）

### 3.2 响应式适配
- **移动端（<768px）**：卡片占满屏幕宽度，内边距 16px

## 🎨 视觉规范

### 4.1 设计规范来源
**设计规范来源**：主题 `src/themes/equatorial-minimalism`

### 4.2 自定义设计要点
无特殊自定义设计，使用主题默认样式。

### 4.3 组件状态
