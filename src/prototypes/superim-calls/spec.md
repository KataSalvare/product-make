# Calls Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | Calls Page |
| **页面路径** | /calls |
| **页面类型** | 功能页 |
| **目标用户** | 已登录用户 |
| **页面目的** | 查看通话记录，发起通话 |

### 1.2 页面描述
通话记录页面，展示语音和视频通话历史，支持快速回拨，查看通话详情。

## 3. 交互逻辑

### 3.1 通话记录操作

#### 点击记录
- 行为：展开通话详情
- 显示：通话时间、时长、类型

#### 通话按钮
- 点击：直接回拨
- 长按：选择语音/视频通话

### 3.2 通话类型标识
| 类型 | 图标 | 颜色 |
|------|------|------|
| 拨出 | ↗️ | 默认 |
| 接入 | ↙️ | 默认 |
| 未接 | ↙️ | 红色 |
| 语音 | 📞 | 默认 |
| 视频 | 📹 | 默认 |

### 3.3 编辑模式
- 点击编辑按钮
- 可选择多条记录删除
- 清空所有记录选项

---

## 4. 内容规范

### 4.1 分组规则
- 今天
- 昨天
- 本周
- 更早（按月份分组）

### 4.2 时长格式
- < 60秒：显示秒数
- ≥ 60秒：MM:SS
- ≥ 60分钟：HH:MM:SS

---

## 5. 异常处理

### 5.1 空状态
- 无记录：显示"No call history"
