# SuperIM 用户列表页规格文档

## 页面信息
- **页面名称**: 用户列表
- **页面路径**: /admin/users
- **所属模块**: 用户管理模块

## 功能描述
展示平台所有注册用户列表，支持搜索、筛选、分页、批量操作等功能，可查看用户详情、封禁/解封用户。

## 组件清单

### 1. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持用户名/昵称/手机号/ID）
  - 用户状态下拉筛选（全部/正常/封禁/未激活）
  - 注册时间范围选择器
  - 搜索按钮
  - 重置按钮

### 2. 批量操作栏
- **组件类型**: 工具栏
- **内容**:
  - 全选复选框
  - 已选数量显示
  - 批量封禁按钮
  - 批量解封按钮
  - 批量删除按钮（需二次确认）

### 3. 用户表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 选择框 | 50px | 单选复选框 |
  | 头像 | 60px | 用户头像，默认显示首字母 |
  | 用户名 | 150px | 用户唯一标识 |
  | 昵称 | 150px | 用户显示名称 |
  | 手机号 | 150px | 脱敏显示 |
  | 状态 | 100px | 正常/封禁/未激活标签 |
  | 注册时间 | 150px | YYYY-MM-DD HH:mm |
  | 操作 | 200px | 查看/编辑/封禁/删除 |

### 4. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50/100）
  - 页码导航
  - 总记录数显示
  - 跳转指定页

### 5. 用户详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 用户基本信息
  - 用户统计（好友数、消息数、动态数）
  - 最近登录记录
  - 操作记录

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 批量操作
1. 勾选表格行选择用户
2. 点击全选选择当前页所有用户
3. 选择批量操作后弹出确认对话框
4. 确认后执行操作并刷新列表

### 单个操作
- **查看**: 打开用户详情抽屉
- **编辑**: 打开编辑对话框（修改昵称、状态等）
- **封禁**: 打开封禁对话框（选择封禁原因和时长）
- **删除**: 二次确认后删除（软删除）

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（手机号、注册时间）
- **移动端**: 卡片式列表展示
