# 用户管理

## 📋 业务与功能

### 1.1 核心目标
> 提供后台用户管理界面，支持用户列表查看、搜索和状态管理

### 1.2 功能清单
- **用户列表**：表格展示所有用户信息
- **搜索过滤**：按用户名或邮箱搜索用户
- **状态标签**：显示用户状态（正常/未激活/已封禁）
- **行操作**：编辑和删除用户入口
- **添加用户**：新建用户入口按钮

### 1.3 交互要点
- 搜索输入 → 实时过滤表格数据
- 状态标签使用 Badge 组件区分不同状态

## 📊 内容规划

### 2.1 信息架构

```
用户管理
├── 页面标题（"用户管理" + 副标题）
├── 用户列表卡片
│   ├── 卡片头部（标题 + 搜索框 + 添加按钮）
│   ├── 表格区域
│   │   ├── 表头：ID / 用户名 / 邮箱 / 状态 / 注册时间 / 操作
│   │   └── 数据行：用户记录
│   └── 空状态（搜索无结果时显示）
```

### 2.2 数据来源
- **数据类型**：模拟用户数据
- **数据源**：页面内 MOCK_USERS 常量
- **关键字段**：
  - `id`: number - 用户 ID
  - `username`: string - 用户名
  - `email`: string - 邮箱
  - `status`: 'active' | 'inactive' | 'banned' - 账号状态
  - `createdAt`: string - 注册时间

### 2.3 内容示例
| ID | 用户名 | 邮箱 | 状态 | 注册时间 |
|----|--------|------|------|---------|
| 1 | 张三 | zhangsan@example.com | 正常 | 2026-01-15 |
| 2 | 李四 | lisi@example.com | 正常 | 2026-02-20 |
| 3 | 王五 | wangwu@example.com | 未激活 | 2026-03-10 |

## 🎨 布局与结构

### 3.1 整体布局
- **布局模式**：全宽单栏，卡片内嵌套表格
- **容器宽度**：流式，内边距 24px
- **表格**：全宽表格，带水平滚动支持

### 3.2 响应式适配
- **移动端（<768px）**：表格水平滚动，保持可读性

## 🎨 视觉规范

### 4.1 设计规范来源
**设计规范来源**：主题 `src/themes/equatorial-minimalism`

### 4.2 自定义设计要点
- 状态标签配色：正常=default（蓝色），未激活=secondary（灰色），已封禁=destructive（红色）

### 4.3 组件状态
- **搜索框**：占位文案提示搜索操作
- **操作按钮**：编辑 = ghost 变体，删除 = ghost + destructive 配色
- **空状态**：居中显示提示文案
