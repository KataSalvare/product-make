# SuperIM 在线用户页规格文档

## 页面信息
- **页面名称**: 在线用户
- **页面路径**: /admin/users/online
- **所属模块**: 用户管理模块

## 功能描述
查看当前在线用户，支持强制下线等操作，实时监控平台活跃用户情况。

## 组件清单

### 1. 在线统计卡片
- **组件类型**: 数据卡片
- **数量**: 4个
- **布局**: 4列等宽
- **卡片内容**:
  - 指标名称
  - 数值 (大字体)
  - 图标

**指标定义**:
| 指标 | 数值 | 图标 | 颜色 |
|------|------|------|------|
| 当前在线 | 1,234 | Activity | 蓝色 |
| 今日峰值 | 2,567 | TrendingUp | 绿色 |
| Web在线 | 234 | Globe | 紫色 |
| 移动端在线 | 1,000 | Smartphone | 橙色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持用户名/用户ID）
  - 设备类型下拉筛选（全部/Web/Android/iOS）
  - 搜索按钮
  - 重置按钮

### 3. 在线用户表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 头像 | 60px | 用户头像 |
  | 用户名 | 150px | 用户唯一标识 |
  | 登录时间 | 150px | 本次登录时间 |
  | 在线时长 | 100px | 持续在线时间 |
  | IP地址 | 120px | 当前IP |
  | 设备 | 150px | 设备类型和版本 |
  | 操作 | 100px | 强制下线 |

### 4. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50）
  - 页码导航
  - 总记录数显示

### 5. 用户详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 用户基本信息
  - 当前会话信息
  - 最近活动记录
  - 强制下线按钮

### 6. 强制下线确认对话框
- **组件类型**: 确认对话框
- **内容**:
  - 强制下线确认提示
  - 下线原因输入框
  - 确认按钮
  - 取消按钮

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 刷新数据
- 点击"刷新"按钮，实时更新在线用户列表

### 强制下线
1. 点击操作列的"强制下线"按钮
2. 弹出确认对话框
3. 输入下线原因
4. 确认后强制用户下线

### 查看详情
- 点击表格行，打开用户详情抽屉，显示用户详细信息和会话详情

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（IP地址、设备）
- **移动端**: 卡片式列表展示
