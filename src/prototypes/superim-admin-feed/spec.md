# SuperIM 动态列表页规格文档

## 页面信息
- **页面名称**: 动态列表
- **页面路径**: /admin/feed
- **所属模块**: 动态管理模块

## 功能描述
管理平台用户发布的动态内容，支持搜索、筛选、审核、删除等操作，维护平台内容健康。

## 组件清单

### 1. 动态统计卡片
- **组件类型**: 数据卡片
- **数量**: 3个
- **布局**: 3列等宽
- **卡片内容**:
  - 指标名称
  - 数值 (大字体)
  - 图标

**指标定义**:
| 指标 | 数值 | 图标 | 颜色 |
|------|------|------|------|
| 今日动态 | 123 | Globe | 蓝色 |
| 待审核 | 5 | Clock | 黄色 |
| 总动态 | 12,345 | Globe | 绿色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持用户名/内容关键词）
  - 状态下拉筛选（全部/正常/审核中/已删除）
  - 时间范围选择器
  - 搜索按钮
  - 重置按钮

### 3. 批量操作栏
- **组件类型**: 工具栏
- **内容**:
  - 全选复选框
  - 已选数量显示
  - 批量审核通过按钮
  - 批量删除按钮（需二次确认）

### 4. 动态表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 选择框 | 50px | 单选复选框 |
  | 用户 | 120px | 发布者用户名 |
  | 内容 | 250px | 动态内容，超长截断 |
  | 图片 | 80px | 图片数量 |
  | 状态 | 100px | 正常/审核中/已删除标签 |
  | 发布时间 | 150px | YYYY-MM-DD HH:mm |
  | 操作 | 150px | 查看/审核/删除 |

### 5. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50）
  - 页码导航
  - 总记录数显示

### 6. 动态详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 用户信息（头像、用户名）
  - 动态完整内容
  - 图片预览
  - 点赞/评论数统计
  - 操作记录

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 批量操作
1. 勾选表格行选择动态
2. 点击全选选择当前页所有动态
3. 选择批量操作后弹出确认对话框
4. 确认后执行操作并刷新列表

### 单个操作
- **查看**: 打开动态详情抽屉
- **审核通过**: 将审核中状态改为正常
- **删除**: 二次确认后删除（软删除）

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（图片、发布时间）
- **移动端**: 卡片式列表展示
