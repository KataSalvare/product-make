# FavoriteDetail Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | FavoriteDetail Page |
| **页面路径** | /favorite/:id |
| **页面类型** | 子页面 |
| **目标用户** | 已登录用户 |
| **页面目的** | 查看单条收藏内容详情，并支持转发或删除 |

### 1.2 页面描述
用户从收藏夹首页点击某条收藏后进入详情页。页面展示收藏来源、时间、类型图标、具体内容（文本/图片/视频/链接/文件），底部提供「转发」按钮，顶部提供「删除」按钮。

---

## 2. 展示逻辑

### 2.1 布局结构
```
┌─────────────────────────────────────┐
│ ← Favorite Detail        🗑️        │ ← Header
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │ [Icon] Source        Time       │ │
│ │                                 │ │
│ │ [图片/视频/链接/文件/文本内容]    │ │
│ └─────────────────────────────────┘ │
├─────────────────────────────────────┤
│         [Forward]                   │ ← 底部操作
└─────────────────────────────────────┘
```

### 2.2 内容卡片
- 类型图标与来源名称
- 收藏时间
- 按类型渲染具体内容：
  - text：文本段落
  - image：大图预览
  - video：封面 + 播放按钮
  - link：可点击标题/URL
  - file：文件名 + 大小

### 2.3 操作
- 转发：跳转 /forward-message
- 删除：确认后返回 /favorites

---

## 3. 主题适配

使用主题变量：
- `--surface` 页面背景
- `--surface-container-lowest` 卡片背景
- `--secondary-container` / `--secondary` 类型图标
- `--primary` / `--on-primary` 转发按钮
- `--error` / `--on-error` 删除按钮
