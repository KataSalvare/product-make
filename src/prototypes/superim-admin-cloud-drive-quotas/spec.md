# SuperIM v1.2 用户存储配额规格

## 页面信息
- 页面名称：用户存储配额
- 页面路径：`/admin/cloud-drive/quotas`
- 所属模块：云盘管理

## 页面目标
让运营人员管理全局默认配额和单用户覆盖，同时直观看到用户已用空间、使用率和文件数。

## 规则
- 全局默认配额初始为 10 GB。
- 单用户覆盖值优先于全局默认值；清除覆盖后恢复全局默认值。
- 任何修改后的配额不得低于该用户当前已用空间；全局默认值不得低于无覆盖用户的已用空间。
- 已用空间包含正常和冻结文件，永久删除后立即释放。
- 全局修改、单用户修改和清除覆盖均写入审计日志。

## 布局与交互
- 顶部提供全局默认配额设置卡和用户/覆盖统计。
- 用户表格展示头像、昵称、用户 ID、有效配额、已用空间、使用率、文件数、最近上传时间和调整入口。
- 单用户调整使用弹窗；留空并确认等同于清除覆盖。
