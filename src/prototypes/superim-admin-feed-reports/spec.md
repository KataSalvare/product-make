# SuperIM 动态举报管理页规格文档

## 页面信息
- **页面名称**: 动态举报管理
- **页面路径**: /admin/feed/reports
- **所属模块**: 动态管理模块

## 功能描述
管理用户举报的动态内容，查看举报详情、处理举报，维护平台动态内容健康。

## 组件清单

### 1. 举报统计卡片
- **组件类型**: 数据卡片
- **数量**: 3个
- **布局**: 3列等宽
- **卡片内容**:
  - 指标名称
  - 数值 (大字体)
  - 图标

**指标定义**:
| 指标 | 数值 | 图标 | 颜色 |
|------|------|------|------|
| 待处理 | 8 | AlertCircle | 红色 |
| 已处理 | 156 | CheckCircle | 绿色 |
| 今日举报 | 5 | Globe | 蓝色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持举报人/被举报人）
  - 举报类型下拉筛选（全部/垃圾广告/色情暴力/骚扰/侵权/其他）
  - 处理状态下拉筛选（全部/待处理/已处理/已驳回）
  - 时间范围选择器
  - 搜索按钮
  - 重置按钮

### 3. 举报列表表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 举报ID | 80px | 举报唯一标识 |
  | 举报人 | 120px | 发起举报的用户 |
  | 被举报人 | 120px | 被举报的用户 |
  | 举报类型 | 100px | 垃圾广告/色情暴力等 |
  | 动态预览 | 200px | 被举报动态内容预览 |
  | 举报时间 | 150px | YYYY-MM-DD HH:mm |
  | 处理状态 | 100px | 待处理/已处理/已驳回 |
  | 操作 | 150px | 处理/查看 |

### 4. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50）
  - 页码导航
  - 总记录数显示

### 5. 举报处理抽屉
- **组件类型**: 抽屉
- **内容**:
  - 举报基本信息（ID、时间、类型）
  - 举报人信息
  - 被举报人信息
  - 被举报动态完整内容
  - 动态图片预览
  - 处理操作区
    - 处理结果选择（通过/驳回）
    - 处理备注输入框
    - 是否删除动态
    - 是否封禁被举报人
    - 封禁时长选择
  - 提交按钮

### 6. 举报详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 举报完整信息
  - 处理结果和备注
  - 处理人信息
  - 处理时间

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 处理举报
1. 点击操作列的"处理"按钮（仅待处理状态）
2. 打开举报处理抽屉
3. 选择处理结果（通过/驳回）
4. 填写处理备注
5. 选择是否删除动态
6. 选择是否封禁及封禁时长
7. 点击提交完成处理

### 查看详情
- 点击操作列的"查看"按钮，打开举报详情抽屉，显示完整举报信息和处理结果

## 响应式设计

- **平板端**: 部分列隐藏（动态预览、举报时间）
- **移动端**: 卡片式列表展示
