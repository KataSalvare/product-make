# SuperIM 系统日志页规格文档

## 页面信息
- **页面名称**: 系统日志
- **页面路径**: /admin/logs/system
- **所属模块**: 日志管理模块

## 功能描述
查看系统运行日志，包括错误日志、警告日志、信息日志等，支持日志搜索、筛选、导出和清空操作。

## 组件清单

### 1. 日志统计卡片
- **组件类型**: 数据卡片
- **数量**: 4个
- **布局**: 4列等宽
- **卡片内容**:
  - 日志级别名称
  - 今日数量 (大字体)
  - 图标

**指标定义**:
| 级别 | 数量 | 图标 | 颜色 |
|------|------|------|------|
| 全部 | 1,234 | FileText | 蓝色 |
| 错误 | 12 | XCircle | 红色 |
| 警告 | 45 | AlertTriangle | 黄色 |
| 信息 | 1,177 | Info | 绿色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持日志内容关键词）
  - 日志级别下拉筛选（全部/ERROR/WARN/INFO/DEBUG）
  - 模块下拉筛选（全部/系统/消息/用户/动态/通话）
  - 时间范围选择器
  - 搜索按钮
  - 重置按钮

### 3. 日志列表表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 时间 | 150px | 日志产生时间 |
  | 级别 | 80px | ERROR/WARN/INFO/DEBUG |
  | 模块 | 100px | 产生日志的模块 |
  | 内容 | 300px | 日志内容摘要 |
  | 操作 | 80px | 查看详情 |

### 4. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（20/50/100）
  - 页码导航
  - 总记录数显示

### 5. 日志详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 日志完整信息
  - 堆栈跟踪（错误日志）
  - 请求ID
  - 用户ID（如有）
  - IP地址
  - 设备信息

### 6. 清空日志确认对话框
- **组件类型**: 确认对话框
- **内容**:
  - 清空确认提示（危险操作）
  - 确认按钮
  - 取消按钮

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 导出日志
- 点击导出按钮，将当前筛选条件下的日志导出为CSV文件

### 清空日志
1. 点击"清空日志"按钮
2. 弹出确认对话框
3. 确认后清空所有日志（危险操作）

### 查看详情
- 点击操作列的"查看"按钮，打开日志详情抽屉，显示完整日志信息

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（模块）
- **移动端**: 卡片式列表展示
