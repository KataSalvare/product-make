# SuperIM 会话列表页规格文档

## 页面信息
- **页面名称**: 会话列表
- **页面路径**: /admin/messages/conversations
- **所属模块**: 消息管理模块

## 功能描述
查看用户会话列表，支持搜索、筛选、查看会话详情，可查看单聊和群聊的会话信息。

## 组件清单

### 1. 会话统计卡片
- **组件类型**: 数据卡片
- **数量**: 3个
- **布局**: 3列等宽
- **卡片内容**:
  - 指标名称
  - 数值 (大字体)
  - 图标

**指标定义**:
| 指标 | 数值 | 图标 | 颜色 |
|------|------|------|------|
| 今日会话 | 1,234 | MessageCircle | 蓝色 |
| 活跃会话 | 567 | MessageSquare | 绿色 |
| 总会话 | 45,678 | Users | 紫色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持用户名/会话ID）
  - 会话类型下拉筛选（全部/单聊/群聊）
  - 时间范围选择器
  - 搜索按钮
  - 重置按钮

### 3. 会话表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 会话ID | 80px | 会话唯一标识 |
  | 参与用户 | 200px | 显示所有参与用户，用标签展示 |
  | 消息数 | 100px | 会话总消息数量 |
  | 最后消息 | 200px | 最后一条消息内容，超长截断 |
  | 最后时间 | 150px | 最后消息时间 |
  | 操作 | 100px | 查看详情按钮 |

### 4. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50）
  - 页码导航
  - 总记录数显示

### 5. 会话详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 会话基本信息（ID、类型、创建时间）
  - 参与用户列表
  - 最近消息预览
  - 消息统计

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 单个操作
- **查看**: 打开会话详情抽屉，显示会话详细信息和消息记录

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（消息数、创建时间）
- **移动端**: 卡片式列表展示
