# SuperIM 版本管理页规格文档

## 页面信息
- **页面名称**: 版本管理
- **页面路径**: /admin/settings/versions
- **所属模块**: 系统设置模块

## 功能描述
管理应用版本发布，查看版本历史，发布新版本，支持版本回滚和强制更新设置。

## 组件清单

### 1. 版本统计卡片
- **组件类型**: 数据卡片
- **数量**: 3个
- **布局**: 3列等宽
- **卡片内容**:
  - 指标名称
  - 数值 (大字体)
  - 图标

**指标定义**:
| 指标 | 数值 | 图标 | 颜色 |
|------|------|------|------|
| 已发布 | 12 | CheckCircle | 绿色 |
| 草稿 | 2 | FileText | 黄色 |
| 总版本 | 14 | GitBranch | 蓝色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持版本号）
  - 平台下拉筛选（全部/Android/iOS/Web）
  - 状态下拉筛选（全部/已发布/草稿/已下线）
  - 搜索按钮
  - 重置按钮

### 3. 版本列表表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 版本号 | 120px | 版本号（如1.0.0） |
  | 平台 | 100px | Android/iOS/Web |
  | 更新内容 | 300px | 更新内容摘要 |
  | 发布时间 | 150px | YYYY-MM-DD HH:mm |
  | 状态 | 100px | 已发布/草稿/已下线 |
  | 操作 | 200px | 编辑/发布/下线/删除 |

### 4. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50）
  - 页码导航
  - 总记录数显示

### 5. 发布/编辑版本对话框
- **组件类型**: 对话框
- **内容**:
  - 版本号输入框（必填，格式x.x.x）
  - 平台选择（Android/iOS/Web）
  - 更新内容编辑器（支持Markdown）
  - 下载链接输入框
  - 强制更新开关
  - 发布状态选择（草稿/立即发布）
  - 确认按钮
  - 取消按钮

### 6. 版本详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 版本完整信息
  - 更新内容预览
  - 下载统计
  - 版本对比

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 发布新版本
1. 点击"发布新版本"按钮
2. 弹出发布对话框
3. 填写版本信息
4. 选择发布状态
5. 点击确认发布

### 编辑版本
1. 点击操作列的"编辑"按钮（仅草稿状态）
2. 弹出编辑对话框，预填充当前数据
3. 修改版本信息
4. 点击确认保存

### 发布草稿
1. 点击操作列的"发布"按钮（仅草稿状态）
2. 确认发布
3. 版本状态变为已发布

### 下线版本
1. 点击操作列的"下线"按钮（仅已发布状态）
2. 确认下线
3. 版本状态变为已下线

### 删除版本
1. 点击操作列的"删除"按钮（仅草稿状态）
2. 弹出确认对话框
3. 确认后删除版本
