# Contacts Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | Contacts Page |
| **页面路径** | /contacts |
| **页面类型** | 功能页 |
| **目标用户** | 已登录用户 |
| **页面目的** | 管理联系人，发起新对话 |

### 1.2 页面描述
联系人管理页面，展示用户的好友列表，支持搜索、添加好友、查看好友资料，快速发起聊天或通话。

## 3. 交互逻辑

### 3.1 联系人操作

#### 点击联系人
- 行为：跳转到 UserProfile 页面
- 显示：联系人详细资料

#### 消息按钮
- 行为：跳转到 ChatRoom
- 创建：新对话或打开已有对话

#### 通话按钮
- 行为：发起语音通话
- 选项：语音/视频通话选择

### 3.2 搜索功能
- 实时搜索：输入时即时过滤
- 搜索范围：姓名、用户名、手机号
- 无结果：显示"No contacts found"

### 3.3 添加联系人
- 点击 + 按钮
- 选项：
  - 从手机通讯录导入
  - 通过用户名搜索
  - 扫描二维码
  - 分享邀请链接

### 3.4 字母索引导航
- 右侧字母列表
- 点击字母：快速滚动到对应分组
- 当前字母：高亮显示

---

## 4. 内容规范

### 4.1 分组规则
- 按联系人姓名首字母分组
- 特殊字符归入 # 组
- 在线联系人可单独分组

### 4.2 排序规则
1. 在线联系人（按姓名排序）
2. 离线联系人（按字母分组排序）

---

## 5. 异常处理

### 5.1 空状态
- 无联系人：显示"No contacts yet" + 添加按钮
- 搜索无结果：显示"No matching contacts"

---
