# SuperIM 通话记录页规格文档

## 页面信息
- **页面名称**: 通话记录
- **页面路径**: /admin/calls
- **所属模块**: 通话管理模块

## 功能描述
查看用户通话记录，包括语音通话和视频通话的详细信息，支持搜索、筛选、导出等功能。

## 组件清单

### 1. 通话统计卡片
- **组件类型**: 数据卡片
- **数量**: 3个
- **布局**: 3列等宽
- **卡片内容**:
  - 指标名称
  - 数值 (大字体)
  - 图标

**指标定义**:
| 指标 | 数值 | 图标 | 颜色 |
|------|------|------|------|
| 今日通话 | 1,234 | Phone | 蓝色 |
| 总通话 | 56,789 | PhoneCall | 绿色 |
| 总时长 | 12,345分钟 | Clock | 紫色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持用户名/手机号）
  - 通话类型下拉筛选（全部/语音/视频）
  - 通话状态下拉筛选（全部/已接通/未接通/已取消）
  - 时间范围选择器
  - 搜索按钮
  - 重置按钮

### 3. 通话记录表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 通话ID | 80px | 通话唯一标识 |
  | 主叫 | 120px | 发起通话用户 |
  | 被叫 | 120px | 接收通话用户 |
  | 类型 | 100px | 语音/视频标签 |
  | 时长 | 100px | 通话时长（分钟:秒） |
  | 状态 | 100px | 已接通/未接通/已取消 |
  | 通话时间 | 150px | YYYY-MM-DD HH:mm |

### 4. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50）
  - 页码导航
  - 总记录数显示

### 5. 通话详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 通话基本信息（ID、类型、状态）
  - 主叫/被叫用户信息
  - 通话时长和质量
  - 网络信息（IP地址、设备信息）

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 导出功能
- 点击导出按钮，将当前筛选条件下的通话记录导出为Excel文件

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（IP地址）
- **移动端**: 卡片式列表展示
