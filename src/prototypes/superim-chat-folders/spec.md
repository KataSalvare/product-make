# ChatFolders Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | ChatFolders Page |
| **页面路径** | /chat-folders |
| **页面类型** | 管理页 |
| **目标用户** | 已登录用户 |
| **页面目的** | 创建、编辑、删除对话文件夹，并将聊天归类 |

### 1.2 页面描述
参考 Telegram 文件夹功能，用户可新建多个文件夹，每个文件夹关联若干单聊/群聊。文件夹数量不限，首页消息列表顶部通过 Tab 切换文件夹视图，默认显示「All」展示全部会话，另有 2 个自定义文件夹（Work / Family）。用户可通过长按/拖拽文件夹卡片调整排序，也可从个人中心的「Manage Folders」入口进入本页。

## 3. 交互逻辑

### 3.1 新建文件夹
- 点击 Header 右上角 + 按钮
- 打开底部弹窗
- 输入名称并选择聊天
- 点击 Create Folder 保存

### 3.2 编辑文件夹
- 点击文件夹卡片上的编辑图标
- 弹窗预填充当前名称和已选聊天
- 修改后保存

### 3.3 删除文件夹
- 点击删除图标
- 弹出确认弹窗
- 确认后仅删除文件夹，不删除聊天

### 3.4 拖动排序
- 长按/拖拽文件夹卡片左侧手柄或整个卡片
- 拖拽过程中被拖动的卡片半透明
- 拖入其他卡片上方时，目标卡片高亮并下移/上移预留位置
- 释放后文件夹顺序即时更新，并持久化到状态

## 4. 主题适配

使用主题变量：
- `--surface` 页面背景
- `--surface-container-lowest` 卡片背景
- `--primary` / `--on-primary` 创建按钮
- `--error` / `--on-error` 删除按钮
- `--outline-variant` 边框
