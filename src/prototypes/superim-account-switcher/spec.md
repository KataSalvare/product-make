# AccountSwitcher Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | AccountSwitcher Page |
| **页面路径** | /account-switcher |
| **页面类型** | 管理页 |
| **目标用户** | 已登录用户 |
| **页面目的** | 管理多个已登录账号并快速切换，最多支持 3 个账号 |

### 1.2 页面描述
用户可在账号切换面板查看当前登录账号及所有其他已登录账号。其他账号若存在未读消息，头像右上角显示未读红点。点击账号即可切换为当前账号，底部提供「添加账号」入口。最多同时登录 3 个账号，达到上限后添加按钮置灰并提示用户。

## 2. 展示逻辑

### 2.1 布局结构
```
┌─────────────────────────────────────┐
│ ← Accounts                          │ ← Header
├─────────────────────────────────────┤
│ Current Account                     │
│ ┌─────────────────────────────────┐ │
│ │ [JD] John Doe      @john.doe ✓  │ │
│ └─────────────────────────────────┘ │
├─────────────────────────────────────┤
│ Other Accounts                      │
│ ┌─────────────────────────────────┐ │
│ │ [WK] Work Account     @john.work│ │
│ │ [FA] Family           @john.family│ │
│ └─────────────────────────────────┘ │
├─────────────────────────────────────┤
│         [Add Account]               │ ← 底部按钮（未达上限）
│  Maximum 3 accounts reached.        │ ← 达到上限时提示
└─────────────────────────────────────┘
```

### 2.2 账号卡片
- 头像（首字母）
- 账号名称与 handle
- 当前账号显示 Active 标签
- 其他账号显示未读红点（数量）

### 2.3 添加账号流程
- 底部按钮打开底部弹窗
- **第一步：选择登录方式并填写账号**
  - Phone / Email Tab 切换
  - Phone 模式：左侧区号选择器（带国旗与国家名），右侧手机号输入框
  - Email 模式：邮箱输入框
  - 点击 Next 进入第二步
- **第二步：输入密码**
  - 显示上一步填写的账号
  - 密码输入框
  - Back 返回第一步，Log In 完成登录并添加账号
- 登录成功后新账号加入列表，保留已登录账号
- 账号总数达到 3 个时，底部 Add Account 按钮置灰，显示 "Maximum 3 accounts reached"

## 3. 主题适配

使用主题变量：
- `--surface` 页面背景
- `--surface-container-lowest` 卡片背景
- `--primary` / `--on-primary` 添加/登录按钮
- `--secondary-container` / `--on-secondary-container` Active 标签
- `--error` / `--on-error` 未读红点
- `--outline-variant` 输入框边框与分隔线
