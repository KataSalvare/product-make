# SuperIM 数据大屏规格文档

## 页面信息
- **页面名称**: 实时数据大屏
- **页面路径**: /admin/bigscreen
- **所属模块**: 数据大屏模块

## 功能描述
全屏展示平台实时运营数据，适用于会议室展示、领导汇报等场景。数据实时刷新，支持多面板轮播。

## 组件清单

### 1. 标题栏
- **组件类型**: 头部栏
- **内容**:
  - 系统 Logo
  - "SuperIM 实时数据监控大屏"
  - 当前时间（实时更新）
  - 退出全屏按钮
  - 关闭按钮

### 2. 核心指标区
- **组件类型**: 指标卡片组
- **布局**: 6列等宽
- **卡片内容**:
  | 指标 | 数值 | 图标 | 颜色 |
  |------|------|------|------|
  | 总注册用户 | 125,432 | Users | 蓝色 |
  | 当前在线 | 1,234 | Activity | 绿色 |
  | 今日新增 | 456 | UserPlus | 橙色 |
  | 今日消息 | 45,678 | MessageSquare | 青色 |
  | 今日通话 | 1,234分钟 | Phone | 紫色 |
  | 待处理举报 | 12 | AlertCircle | 红色 |

### 3. 用户地图分布
- **组件类型**: 地图可视化
- **内容**: 非洲地图热力图
- **数据**: 按国家显示用户密度
- **交互**: 悬停显示具体数值

### 4. 实时动态流
- **组件类型**: 滚动列表 + 折线图
- **内容**:
  - 最新注册用户（自动滚动）
  - 24小时在线人数曲线

### 5. 消息类型分布
- **组件类型**: 组合图表
- **内容**:
  - 饼图：消息类型占比
  - 柱状图：单聊/群聊对比

### 6. 用户增长趋势
- **组件类型**: 折线图
- **内容**: 30天用户增长曲线
- **线条**: 新增用户、活跃用户、流失用户

## 交互行为

### 自动刷新
- 数据每 5 秒自动刷新
- 刷新时有动画过渡效果

### 全屏模式
- 页面默认全屏显示
- ESC 键退出全屏
- 点击退出按钮退出全屏

### 面板轮播
- 每 30 秒自动切换面板
- 支持手动切换
- 显示轮播指示器
