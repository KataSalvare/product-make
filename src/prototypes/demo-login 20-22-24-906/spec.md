# 登录页 PRD

## 页面目标

提供统一的账号登录入口，支持邮箱/用户名 + 密码登录，以及第三方授权登录。

## 功能范围

- 邮箱 / 用户名输入
- 密码输入
- 记住我（7 天免登录）
- 忘记密码跳转
- 登录按钮与表单校验
- 第三方登录：微信、GitHub、企业微信
- 注册入口跳转

## 交互说明

1. **品牌展示区**
   Logo + 欢迎语，可根据品牌自定义配色。点击 Logo 可跳转首页。

2. **用户名输入框**
   支持邮箱或用户名登录。输入后失焦触发格式校验。无输入时显示红色错误提示。

3. **密码输入框**
   密码支持明文/密文切换（后续迭代）。输入时边框变色。

4. **记住我功能**
   勾选后 7 天内免登录（Token 存 localStorage）。未勾选 Session 过期即退出。敏感操作仍需二次验证。

5. **忘记密码流程**
   点击跳转找回密码页。流程：输入邮箱 → 获取验证码 → 重置密码 → 完成。验证码有效期 5 分钟。

6. **登录按钮交互**
   点击后全表单校验。通过 → "登录中..." → 1.5s 模拟成功。失败 → 对应字段标红并提示错误信息。

7. **第三方登录**
   微信：唤起扫码授权。GitHub：OAuth 跳转。企业微信：企业内应用授权。

8. **注册入口**
   无账号用户跳转注册页。注册成功自动登录并跳转首页。

## 业务逻辑

- 登录态有效期：记住我 7 天，未记住我浏览器 Session。
- 密码错误 5 次锁定账号 15 分钟。
- 登录成功后记录最后登录时间，用于安全提醒。
