# SuperIM 登录日志页规格文档

## 页面信息
- **页面名称**: 登录日志
- **页面路径**: /admin/logs/login
- **所属模块**: 日志管理模块

## 功能描述
查看管理员登录日志，记录所有登录行为，包括登录成功和失败记录，支持安全审计。

## 组件清单

### 1. 登录统计卡片
- **组件类型**: 数据卡片
- **数量**: 3个
- **布局**: 3列等宽
- **卡片内容**:
  - 指标名称
  - 数值 (大字体)
  - 图标

**指标定义**:
| 指标 | 数值 | 图标 | 颜色 |
|------|------|------|------|
| 今日登录 | 45 | LogIn | 蓝色 |
| 成功 | 42 | CheckCircle | 绿色 |
| 失败 | 3 | XCircle | 红色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持管理员用户名）
  - 管理员下拉筛选（全部/具体管理员列表）
  - 状态下拉筛选（全部/成功/失败）
  - 时间范围选择器
  - 搜索按钮
  - 重置按钮

### 3. 登录日志表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 时间 | 150px | 登录时间 |
  | 管理员 | 120px | 登录管理员 |
  | 登录方式 | 100px | 账号密码/验证码 |
  | 状态 | 80px | 成功/失败 |
  | IP地址 | 120px | 登录IP |
  | 设备信息 | 200px | 浏览器/操作系统 |

### 4. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50）
  - 页码导航
  - 总记录数显示

### 5. 登录详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 登录完整信息
  - 登录失败原因（失败时）
  - 地理位置信息
  - 设备详细信息

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 导出日志
- 点击导出按钮，将当前筛选条件下的登录日志导出为Excel文件

### 查看详情
- 点击表格行，打开登录详情抽屉，显示完整登录信息

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（设备信息）
- **移动端**: 卡片式列表展示
