# Forgot Password Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | Forgot Password Page |
| **页面路径** | /forgotpassword |
| **页面类型** | 认证页 |
| **目标用户** | 忘记密码的未登录用户 |
| **页面目的** | 通过手机号或邮箱验证码完成密码重置 |

### 1.2 页面描述
忘记密码页面，支持手机号和邮箱两种方式接收验证码，验证通过后设置新密码，完成后引导用户回到登录页。采用分步流程，减少用户认知负担。

## 3. 交互逻辑

### 3.1 分步流程

```
Step 1: 输入手机号/邮箱
        │
        ▼
   点击 "Send Reset Code"
        │
        ▼
   显示 Step 2: 输入验证码
        │
        ▼
   点击 "Verify & Next"
        │
        ▼
   显示 Step 3: 设置新密码
        │
        ▼
   点击 "Reset Password"
        │
        ▼
   显示 Step 4: 成功状态
        │
        ▼
   点击 "Back to Login" → 返回登录页
```

### 3.2 Tab 切换

#### Phone Tab
- 显示：国家码选择器 + 手机号输入框
- 验证方式：短信验证码

#### Email Tab
- 显示：邮箱输入框
- 验证方式：邮件验证码

### 3.3 步骤详情

#### Step 1 — 输入账号
| 条件 | 说明 |
|------|------|
| 手机号为空 | 按钮禁用 |
| 邮箱为空 | 按钮禁用 |
| 已发送验证码 | 按钮变为 "Resend Code (Xs)" 倒计时 |

#### Step 2 — 输入验证码
| 条件 | 说明 |
|------|------|
| 验证码为空 | "Verify & Next" 按钮禁用 |
| 验证码长度 < 6 | 按钮禁用 |
| 倒计时期间 | "Resend (Xs)" 不可点击 |
| 倒计时结束 | "Resend" 可点击 |

#### Step 3 — 设置新密码
| 条件 | 说明 |
|------|------|
| 新密码 < 6 位 | 按钮禁用 |
| 两次密码不一致 | 显示错误提示 |
| 密码一致 且 ≥ 6 位 | 按钮可用 |

#### Step 4 — 成功状态
- 显示绿色勾图标
- "Password Reset Successful!" 标题
- "Your password has been updated. Please sign in with your new password."
- "Back to Login" 按钮跳转到登录页

### 3.4 密码强度提示
| 强度 | 条件 | 颜色 |
|------|------|------|
| Weak | < 8 位 或 仅字母/数字 | 红色 |
| Medium | ≥ 8 位 + 两种字符类型 | 黄色 |
| Strong | ≥ 8 位 + 大写 + 数字 + 符号 | 绿色 |

### 3.5 生命周期
```
挂载 → 显示 Step 1
         → Step 2 (验证码发送后)
         → Step 3 (验证通过后)
         → Step 4 (密码重置成功)
```

## 5. 异常处理

### 5.1 网络错误
- 发送验证码失败：显示 "Failed to send code. Please try again."
- 验证失败：显示 "Invalid verification code"

### 5.2 密码规则
- 新密码不能与旧密码相同
- 密码长度至少 6 位
- 两次输入不一致时显示红色提示

### 5.3 边界情况
- 连续点击防抖处理
- 步骤切换动画流畅
