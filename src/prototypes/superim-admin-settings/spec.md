# SuperIM 基础配置页规格文档

## 页面信息
- **页面名称**: 基础配置
- **页面路径**: /admin/settings/general
- **所属模块**: 系统设置模块

## 功能描述
配置系统基础参数，包括应用信息、注册设置、消息设置、安全设置等，支持配置的导入导出。

## 组件清单

### 1. 应用信息配置卡片
- **组件类型**: 配置卡片
- **内容**:
  - 应用名称输入框（必填）
  - 应用Logo上传（支持拖拽上传）
  - 应用版本显示（只读）
  - 应用描述文本域

### 2. 注册设置配置卡片
- **组件类型**: 配置卡片
- **内容**:
  - 开放注册开关
  - 验证码开关
  - 邀请码注册开关
  - 邀请码输入框（开启邀请码注册时显示）
  - 注册协议编辑器

### 3. 消息设置配置卡片
- **组件类型**: 配置卡片
- **内容**:
  - 消息保留时长选择（7天/30天/90天/永久）
  - 单聊消息每日限制输入框
  - 群聊消息每日限制输入框
  - 文件大小限制输入框（MB）

### 4. 安全设置配置卡片
- **组件类型**: 配置卡片
- **内容**:
  - 登录失败次数限制输入框
  - 登录锁定时间选择（15分钟/30分钟/1小时/24小时）
  - 密码强度要求选择（低/中/高）
  - 会话超时时间选择（30分钟/1小时/2小时/4小时）

### 5. 导入配置对话框
- **组件类型**: 对话框
- **内容**:
  - 配置文件上传（JSON格式）
  - 配置预览
  - 确认导入按钮
  - 取消按钮

### 6. 导出配置对话框
- **组件类型**: 对话框
- **内容**:
  - 选择导出配置项
  - 导出按钮
  - 取消按钮

## 交互行为

### 保存配置
1. 修改任意配置项
2. 点击"保存"按钮
3. 验证配置有效性
4. 保存成功提示

### 导入配置
1. 点击"导入配置"按钮
2. 弹出导入对话框
3. 上传配置文件
4. 预览配置内容
5. 确认导入

### 导出配置
1. 点击"导出配置"按钮
2. 弹出导出对话框
3. 选择要导出的配置项
4. 点击导出，下载配置文件

## 响应式设计

- **平板端**: 配置卡片双列布局
- **移动端**: 配置卡片单列布局
