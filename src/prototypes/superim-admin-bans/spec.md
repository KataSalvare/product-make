# SuperIM 封禁管理页规格文档

## 页面信息
- **页面名称**: 封禁管理
- **页面路径**: /admin/users/bans
- **所属模块**: 用户管理模块

## 功能描述
管理被封禁的用户账号，查看封禁记录，支持解封操作，维护平台秩序。

## 组件清单

### 1. 封禁统计卡片
- **组件类型**: 数据卡片
- **数量**: 3个
- **布局**: 3列等宽
- **卡片内容**:
  - 指标名称
  - 数值 (大字体)
  - 图标

**指标定义**:
| 指标 | 数值 | 图标 | 颜色 |
|------|------|------|------|
| 今日封禁 | 12 | Ban | 红色 |
| 今日解封 | 3 | Unlock | 绿色 |
| 总封禁 | 456 | UserX | 橙色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持用户名/用户ID）
  - 封禁原因下拉筛选（全部/违规发言/垃圾广告/恶意骚扰/其他）
  - 状态下拉筛选（全部/封禁中/已解封）
  - 时间范围选择器
  - 搜索按钮
  - 重置按钮

### 3. 封禁记录表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 用户 | 150px | 被封禁用户信息 |
  | 封禁原因 | 120px | 违规类型标签 |
  | 封禁时间 | 150px | 封禁操作时间 |
  | 解封时间 | 150px | 预计/实际解封时间 |
  | 操作人 | 120px | 执行封禁的管理员 |
  | 状态 | 100px | 封禁中/已解封 |
  | 操作 | 120px | 解封/查看详情 |

### 4. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50）
  - 页码导航
  - 总记录数显示

### 5. 封禁详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 用户基本信息
  - 封禁详情（原因、时长、操作人）
  - 违规证据（如有）
  - 历史封禁记录
  - 解封操作按钮

### 6. 解封确认对话框
- **组件类型**: 确认对话框
- **内容**:
  - 解封确认提示
  - 解封原因输入框
  - 确认按钮
  - 取消按钮

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 解封操作
1. 点击操作列的"解封"按钮
2. 弹出解封确认对话框
3. 输入解封原因
4. 确认后解封用户并刷新列表

### 查看详情
- 点击操作列的"查看"按钮，打开封禁详情抽屉，显示完整封禁信息和历史记录

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（操作人、封禁时间）
- **移动端**: 卡片式列表展示
