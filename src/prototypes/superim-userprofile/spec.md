# UserProfile Page PRD

## 1. 页面概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | UserProfile Page |
| **页面路径** | /profile/:id |
| **页面类型** | 信息页 |
| **目标用户** | 已登录用户 |
| **页面目的** | 查看联系人详细信息 |

### 1.2 页面描述
用户资料页面，展示联系人的详细信息，包括头像、昵称、用户名、个人简介、联系方式等，提供快速发起对话和通话的入口。

## 3. 交互逻辑

### 3.1 头像操作
- 点击：查看大图
- 长按：保存图片

### 3.2 操作按钮

| 按钮 | 行为 |
|------|------|
| Message | 跳转到 ChatRoom |
| Voice | 发起语音通话 |
| Video | 发起视频通话 |

### 3.3 更多选项
- 点击右上角 ⠇
- 选项：
  - Share Contact
  - Edit Contact
  - Block User
  - Report
  - Delete Contact

### 3.4 信息项操作
- 点击 Phone：复制号码
- 点击 Location：打开地图

---

## 4. 内容规范

### 4.1 信息显示
| 字段 | 格式 |
|------|------|
| 姓名 | 首字母大写 |
| 用户名 | @username 小写 |
| 电话 | +XXX XXX XXX XXXX |
| 位置 | 城市, 国家 |
| 加入时间 | Month YYYY |
