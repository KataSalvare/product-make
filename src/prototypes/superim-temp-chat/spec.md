# 临时会话页面规格说明

## 1. 概述

### 1.1 页面信息
| 项目 | 内容 |
|------|------|
| **页面名称** | 临时会话 |
| **路径** | /temp-chat/:userId |
| **页面类型** | 子页面 |
| **目标用户** | 已登录用户 |
| **页面目的** | 与非好友用户发起临时对话，1 小时后自动销毁 |

### 1.2 功能描述
用户可通过搜索或通讯录入口进入临时会话页面。页面顶部显示「Temp Chat」标签和倒计时条；剩余时间不足 5 分钟时，倒计时条变红并提示添加好友。用户可随时添加对方为好友，将临时会话转为正式会话并保留历史消息。

## 2. 展示逻辑

### 2.1 布局结构
```
┌─────────────────────────────────────┐
│ ← 头像  用户名            [更多 ⋮]  │ ← 顶部导航栏
├─────────────────────────────────────┤
│ ⏱ 59:51 后自动销毁        [Add Friend] │ ← 倒计时条
├─────────────────────────────────────┤
│                                     │
│      左/右消息气泡                   │
│      （长按弹出操作菜单）              │
│                                     │
├─────────────────────────────────────┤
│ [输入框] [发送]                      │ ← 输入栏
└─────────────────────────────────────┘
```

#### 多选模式布局
```
┌─────────────────────────────────────┐
│ ✕  N Selected            [删除 🗑]  │ ← 多选顶部栏
├─────────────────────────────────────┤
│ ○  ┌────────────┐                   │
│ ●  │ 收到的消息  │                   │
│    └────────────┘                   │
│ ○            ┌────────────┐         │
│ ●            │ 发出的消息  │         │
│              └────────────┘         │
├─────────────────────────────────────┤
│      [Forward (N)]                  │ ← 底部转发栏
└─────────────────────────────────────┘
```

### 2.2 视觉层级
| 层级 | 元素 | 说明 |
|------|------|------|
| 1 | 顶部导航栏 | 返回、头像、用户名、「Temp Chat」标签、更多操作按钮 |
| 2 | 倒计时条 | 正常状态使用 secondary-container；不足 5 分钟使用 error 背景 |
| 3 | 消息列表 | 复用正式聊天室的气泡样式 |
| 4 | 输入栏 | 与单聊发送操作栏保持一致：附件按钮、带表情按钮的输入框、语音/发送按钮；图标按钮与输入框垂直居中对齐 |

### 2.3 倒计时规则
- 初始剩余时间：1 小时（3600 秒）
- 每秒刷新一次
- 剩余时间 ≤ 300 秒时，倒计时条背景变为 error，文案提示「Temp chat will expire soon」
- 剩余时间为 0 时，全屏显示会话已过期遮罩

### 2.4 添加好友
- 触发位置：倒计时条右侧的「Add Friend」按钮，或右上角更多菜单中的「Add Friend」选项
- 点击后弹出二次确认弹窗
- 确认后，临时会话转为正式会话，显示「Converted to official chat」成功提示

### 2.5 更多操作菜单
- 触发位置：右上角「⋮」图标按钮
- 菜单选项：
  - **Add Friend**：添加好友并转正
  - **Clear History**：清空当前聊天记录
  - **Delete Chat**：删除该临时会话
- 点击「清空记录」或「删除对话」时，需再次弹出二次确认弹窗

## 3. 交互逻辑

### 3.1 发送消息
- 输入文字后点击发送按钮或按回车键
- 消息显示在右侧
- 已读状态使用双勾图标

### 3.2 添加好友转正
- 触发：点击「Add Friend」按钮或更多菜单中的「Add Friend」
- 确认后：设置 `isConverted=true`
- 倒计时停止，倒计时条和销毁提示消失
- 顶部「Temp Chat」标签保持不变，提示转为正式会话

### 3.3 会话过期
- 倒计时归零后，全屏显示「Temp Chat Expired」遮罩
- 提供「Add Friend」入口，添加好友后可继续聊天

### 3.4 清空记录
- 触发：更多菜单 → Clear History
- 二次确认弹窗提示「清空后不可恢复」
- 确认后清空当前消息列表

### 3.5 删除对话
- 触发：更多菜单 → Delete Chat
- 二次确认弹窗提示「删除后聊天将从列表移除」
- 确认后关闭页面或返回聊天列表

### 3.6 消息操作菜单
- 触发：在任意消息上右键（桌面端）或长按（移动端，约 600ms）
- 菜单位置跟随触发点，自动避让屏幕边缘
- 菜单项（与单聊保持一致，去除 Pin 和 Save to Favorites）：
  - **Reply**：回复当前消息，输入栏上方显示回复预览条，发送后消息附带引用
  - **Copy**：复制消息文本到剪贴板
  - **Forward**：跳转到 `/forward-message` 转发当前消息
  - **Select**：进入多选模式，并自动选中当前消息
  - **Delete**：弹出二次确认弹窗，确认后删除该消息
- 已过期会话不响应长按/右键操作

### 3.7 多选模式
- 进入方式：消息菜单 → Select
- 状态：
  - `isMultiSelectMode`：是否处于多选模式
  - `selectedMessageIds`：当前选中的消息 ID 数组
- 视觉表现：
  - 所有消息左侧显示圆形复选框，形成屏幕左侧一列
  - 发出的消息仍右对齐，收到的消息仍左对齐
  - 顶部栏替换为「关闭 ✕ + N Selected + 删除 🗑」
  - 底部输入栏替换为「Forward (N)」按钮
  - 倒计时条、转正提示条、输入栏、表情面板、附件面板在多选模式下隐藏
- 交互：
  - 点击消息气泡或复选框切换选中状态
  - 点击顶部关闭按钮退出多选并清空选择
  - 点击顶部删除按钮：弹出二次确认弹窗，确认后移除所有选中消息并退出多选
  - 点击底部 Forward 按钮：跳转至 `/forward-message`，并退出多选

## 4. 主题 Token

- `--surface-container-low`：页面背景
- `--surface-container-lowest`：消息气泡背景
- `--secondary` / `--on-secondary`：添加好友按钮
- `--error` / `--on-error`：强提醒背景
- `--primary-container` / `--on-primary-container`：转正成功提示背景
