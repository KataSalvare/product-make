# SuperIM 操作日志页规格文档

## 页面信息
- **页面名称**: 操作日志
- **页面路径**: /admin/logs/operation
- **所属模块**: 日志管理模块

## 功能描述
查看管理员操作日志，记录所有后台操作行为，支持安全审计和问题追溯。

## 组件清单

### 1. 操作统计卡片
- **组件类型**: 数据卡片
- **数量**: 4个
- **布局**: 4列等宽
- **卡片内容**:
  - 操作类型名称
  - 今日数量 (大字体)
  - 图标

**指标定义**:
| 类型 | 数量 | 图标 | 颜色 |
|------|------|------|------|
| 今日操作 | 123 | Activity | 蓝色 |
| 创建 | 15 | PlusCircle | 绿色 |
| 更新 | 89 | Edit | 黄色 |
| 删除 | 19 | Trash2 | 红色 |

### 2. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持操作内容关键词）
  - 管理员下拉筛选（全部/具体管理员列表）
  - 操作类型下拉筛选（全部/创建/更新/删除/查询/导出/登录/登出）
  - 时间范围选择器
  - 搜索按钮
  - 重置按钮

### 3. 操作日志表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 时间 | 150px | 操作时间 |
  | 管理员 | 120px | 操作管理员 |
  | 操作类型 | 100px | 创建/更新/删除等 |
  | 操作对象 | 150px | 操作的数据对象 |
  | 操作内容 | 250px | 操作详情摘要 |
  | IP地址 | 120px | 操作IP |

### 4. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50）
  - 页码导航
  - 总记录数显示

### 5. 操作详情抽屉
- **组件类型**: 抽屉
- **内容**:
  - 操作完整信息
  - 操作前数据（更新/删除时）
  - 操作后数据（创建/更新时）
  - 数据变更对比

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 导出日志
- 点击导出按钮，将当前筛选条件下的操作日志导出为Excel文件

### 查看详情
- 点击表格行，打开操作详情抽屉，显示完整操作信息和数据变更对比

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（操作内容）
- **移动端**: 卡片式列表展示
