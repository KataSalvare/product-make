# SuperIM 后台登录页规格文档

## 页面信息
- **页面名称**: 管理员登录
- **页面路径**: /admin/login
- **所属模块**: 认证模块

## 功能描述
管理员身份认证入口，提供安全的登录机制，包括账号密码验证、图形验证码、登录安全保护等功能。

### 布局规则
- 页面背景: 渐变色背景 (#1E40AF 到 #3B82F6)
- 登录卡片: 居中显示，最大宽度 420px
- 卡片样式: 白色背景，圆角 16px，阴影效果
- 内边距: 40px

## 组件清单

### 1. Logo 区域
- **组件类型**: 展示组件
- **内容**: 
  - 系统 Logo（48px）
  - 标题 "SuperIM Admin"
  - 副标题 "后台管理系统"
- **样式**: 居中对齐，标题 24px 加粗

### 2. 账号输入框
- **组件类型**: 输入框
- **占位符**: "请输入账号（邮箱/用户名）"
- **前缀图标**: User 图标
- **验证规则**: 
  - 必填
  - 最少 3 个字符
- **交互**: 聚焦时边框高亮

### 3. 密码输入框
- **组件类型**: 密码输入框
- **占位符**: "请输入密码"
- **前缀图标**: Lock 图标
- **后缀图标**: Eye / EyeOff（显示/隐藏切换）
- **验证规则**: 
  - 必填
  - 最少 6 个字符
- **交互**: 点击后缀图标切换显示/隐藏

### 4. 图形验证码
- **组件类型**: 组合输入
- **布局**: 输入框 + 验证码图片（右侧）
- **输入框**: 
  - 占位符 "请输入验证码"
  - 前缀图标: Shield 图标
  - 宽度: 60%
- **验证码图片**: 
  - 宽度: 38%
  - 高度: 40px
  - 点击刷新
  - 4位数字/字母组合

### 5. 记住我
- **组件类型**: 复选框
- **标签**: "记住我"
- **默认状态**: 未选中
- **说明**: 7天内自动登录

### 6. 登录按钮
- **组件类型**: 按钮
- **文本**: "登 录"
- **样式**: 
  - 主色背景 (#1E40AF)
  - 白色文字
  - 圆角 8px
  - 高度 44px
  - 全宽
- **状态**: 
  - 默认: 可点击
  - 加载中: 显示 Loading 图标，禁用
  - 禁用: 表单验证未通过时

### 7. 忘记密码链接
- **组件类型**: 文本链接
- **文本**: "忘记密码？"
- **样式**: 主色文字，悬停下划线
- **交互**: 点击跳转密码重置页面

## 交互行为

### 表单验证
1. **实时验证**: 输入框失焦时验证
2. **提交验证**: 点击登录时全量验证
3. **错误提示**: 输入框下方显示红色错误信息

### 登录流程
1. 用户填写表单
2. 点击登录按钮
3. 按钮进入加载状态
4. 验证账号密码
5. 验证通过 → 跳转 Dashboard
6. 验证失败 → 显示错误提示，刷新验证码

### 安全机制
- 连续 5 次登录失败锁定账号 30 分钟
- 登录 IP 异常记录
- 密码错误提示模糊化（不提示账号是否存在）
