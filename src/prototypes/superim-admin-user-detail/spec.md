# SuperIM 用户详情页规格文档

## 页面信息
- **页面名称**: 用户详情
- **页面路径**: /admin/users/:id
- **所属模块**: 用户管理模块

## 功能描述
查看用户详细信息，包括基本信息、统计数据、好友列表、消息记录、动态内容、登录记录等，支持编辑用户信息、封禁/解封用户、重置密码等操作。

## 组件清单

### 1. 页面标题栏
- **组件类型**: 标题栏
- **内容**:
  - 返回按钮（返回用户列表）
  - 页面标题 "用户详情"
  - 操作按钮组：编辑、封禁/解封、重置密码

### 2. 用户基本信息卡片
- **组件类型**: 信息卡片
- **内容**:
  - 用户头像（大尺寸 80px）
  - 用户名
  - 昵称
  - 手机号（脱敏显示）
  - 邮箱
  - 状态标签（正常/封禁/未激活）
  - 注册时间
  - 最后登录时间
  - 用户ID

### 3. 用户统计卡片
- **组件类型**: 统计卡片组
- **布局**: 2列 x 3行
- **指标定义**:

| 指标 | 数值 | 图标 | 颜色 |
|------|------|------|------|
| 好友数 | 128 | Users | 蓝色 |
| 消息数 | 5,234 | MessageSquare | 绿色 |
| 动态数 | 45 | Globe | 橙色 |
| 通话时长 | 320分钟 | Phone | 紫色 |
| 注册天数 | 365天 | Calendar | 青色 |
| 活跃度 | 高 | Activity | 粉色 |

### 4. Tab 切换栏
- **组件类型**: 标签页
- **标签项**:
  - 好友列表
  - 消息记录
  - 动态内容
  - 登录记录
  - 操作日志

### 5. 好友列表 Tab
- **组件类型**: 表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 头像 | 60px | 好友头像 |
  | 用户名 | 150px | 好友用户名 |
  | 昵称 | 150px | 好友昵称 |
  | 添加时间 | 150px | 成为好友时间 |
  | 操作 | 100px | 查看详情 |

### 6. 消息记录 Tab
- **组件类型**: 时间线
- **内容**:
  - 消息时间
  - 消息类型（发送/接收）
  - 消息内容预览
  - 对方用户
  - 会话类型（单聊/群聊）

### 7. 动态内容 Tab
- **组件类型**: 卡片列表
- **内容**:
  - 动态内容
  - 图片缩略图
  - 发布时间
  - 点赞数
  - 评论数
  - 状态（正常/已删除）

### 8. 登录记录 Tab
- **组件类型**: 表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 登录时间 | 150px | 登录时间 |
  | IP地址 | 150px | 登录IP |
  | 设备 | 200px | 设备类型和版本 |
  | 位置 | 150px | 登录地点 |
  | 状态 | 100px | 成功/失败 |

### 9. 操作日志 Tab
- **组件类型**: 时间线
- **内容**:
  - 操作时间
  - 操作类型
  - 操作内容
  - 操作人（管理员）

### 10. 编辑用户对话框
- **组件类型**: 对话框
- **内容**:
  - 昵称输入框
  - 手机号输入框
  - 邮箱输入框
  - 状态选择（正常/封禁）
  - 确认按钮
  - 取消按钮

### 11. 封禁用户对话框
- **组件类型**: 对话框
- **内容**:
  - 封禁原因选择（违规发言/垃圾广告/恶意骚扰/其他）
  - 封禁时长选择（1天/7天/30天/永久）
  - 备注输入框
  - 确认按钮
  - 取消按钮

### 12. 重置密码对话框
- **组件类型**: 对话框
- **内容**:
  - 新密码输入框
  - 确认密码输入框
  - 确认按钮
  - 取消按钮

## 交互行为

### 页面加载
1. 从URL获取用户ID参数
2. 调用API获取用户详细信息
3. 渲染页面各组件
4. 默认显示"好友列表"Tab

### Tab切换
1. 点击Tab标签
2. 加载对应Tab的数据
3. 切换显示内容区域

### 编辑用户
1. 点击"编辑"按钮
2. 弹出编辑对话框，填充当前用户信息
3. 修改信息后点击确认
4. 调用API保存修改
5. 刷新页面显示

### 封禁用户
1. 点击"封禁"按钮
2. 弹出封禁对话框
3. 选择封禁原因和时长
4. 点击确认
5. 调用API执行封禁
6. 刷新用户状态显示

### 重置密码
1. 点击"重置密码"按钮
2. 弹出重置密码对话框
3. 输入新密码
4. 点击确认
5. 调用API重置密码
6. 显示成功提示

### 查看好友详情
1. 点击好友列表中的"查看详情"
2. 跳转到对应好友的用户详情页

## 响应式设计
- **桌面端(≥1280px)**: 双列布局，信息卡片和统计卡片并排
- **平板端(768-1279px)**: 单列布局，Tab内容区域横向滚动
- **移动端(<768px)**: 单列布局，Tab切换为下拉选择器
