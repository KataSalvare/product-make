# SuperIM 管理员列表页规格文档

## 页面信息
- **页面名称**: 管理员列表
- **页面路径**: /admin/admins
- **所属模块**: 权限管理模块

## 功能描述
管理后台管理员账号，包括添加、编辑、删除、重置密码、启用/禁用等操作，实现管理员账号全生命周期管理。

## 组件清单

### 1. 搜索栏
- **组件类型**: 组合搜索
- **内容**:
  - 搜索输入框（支持用户名/姓名）
  - 角色下拉筛选（全部/超级管理员/运营专员/客服专员/审计员）
  - 状态下拉筛选（全部/启用/禁用）
  - 搜索按钮
  - 重置按钮

### 2. 管理员列表表格
- **组件类型**: 数据表格
- **列定义**:
  | 列名 | 宽度 | 说明 |
  |------|------|------|
  | 头像 | 60px | 管理员头像，默认显示首字母 |
  | 用户名 | 150px | 登录账号 |
  | 姓名 | 120px | 真实姓名 |
  | 角色 | 120px | 所属角色 |
  | 状态 | 100px | 启用/禁用 |
  | 最后登录 | 150px | YYYY-MM-DD HH:mm |
  | 操作 | 200px | 编辑/重置密码/启用禁用/删除 |

### 3. 分页器
- **组件类型**: 分页
- **功能**:
  - 每页显示数量选择（10/20/50）
  - 页码导航
  - 总记录数显示

### 4. 添加/编辑管理员对话框
- **组件类型**: 对话框
- **内容**:
  - 用户名输入框（必填，唯一）
  - 姓名输入框（必填）
  - 邮箱输入框
  - 手机号输入框
  - 角色选择（必填）
  - 初始密码输入框（添加时必填）
  - 确认按钮
  - 取消按钮

### 5. 重置密码对话框
- **组件类型**: 对话框
- **内容**:
  - 新密码输入框
  - 确认密码输入框
  - 确认按钮
  - 取消按钮

### 6. 删除确认对话框
- **组件类型**: 确认对话框
- **内容**:
  - 删除确认提示
  - 确认按钮（危险操作）
  - 取消按钮

## 交互行为

### 搜索筛选
1. 输入关键词后点击搜索或按回车
2. 筛选条件改变后自动触发搜索
3. 重置按钮清空所有条件

### 添加管理员
1. 点击"添加管理员"按钮
2. 弹出添加对话框
3. 填写管理员信息
4. 点击确认添加

### 编辑管理员
1. 点击操作列的"编辑"按钮
2. 弹出编辑对话框，预填充当前数据
3. 修改管理员信息
4. 点击确认保存

### 重置密码
1. 点击操作列的"重置密码"按钮
2. 弹出重置密码对话框
3. 输入新密码和确认密码
4. 点击确认重置

### 启用/禁用
1. 点击操作列的"启用"或"禁用"按钮
2. 切换管理员账号状态

### 删除管理员
1. 点击操作列的"删除"按钮
2. 弹出确认对话框
3. 确认后删除管理员（不能删除自己）

## 响应式设计
- **桌面端**: 完整表格展示
- **平板端**: 部分列隐藏（邮箱、最后登录）
- **移动端**: 卡片式列表展示
